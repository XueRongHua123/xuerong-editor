# 国策树编辑器 · 使用教程

本工具用于可视化查看和编辑 HOI4 国策树，直接读写 mod 文件，并可导出覆盖包分享给他人。

## 一、启动

- **双击 exe**（或命令行运行 `python focus_editor.py`）；
- 启动后先打开编辑器页面，在欢迎页点「选择 mod 文件夹」：会弹出**页内文件夹浏览器**，点进文件夹或直接粘贴路径，再点「选择此文件夹」；
- 之后想追加子模组，点左侧「＋ 添加 mod」即可（后加载的覆盖同 ID 国策树）。

### 新建模组（直接基于原版做 mod）

左侧「🆕 新建模组」：

- 填写模组文件夹名、显示名称、版本、游戏版本；
- 可勾选「创建示例国策树」，并指定国策树 ID 与国家 TAG；
- 工具会生成 `descriptor.mod`、示例国策树（`common/national_focus`）和中英本地化；
- 若保存位置是 HOI4 的 `mod` 目录，还会自动生成启动器 `.mod` 文件，启动器里直接启用即可；
- 创建后会自动加载进编辑器。不会替换原版文件，适合直接在原版基础上加内容。
- 需要同时加载本体 + 子模组时，用命令行按顺序传入：

```
FocusTreeEditor.exe --mod "本体目录" --mod "子模组目录"
```

后加载的同 ID 国策树会覆盖先加载的（与游戏内加载顺序一致）。

可选参数：`--port 8765` 换端口；`--game "HOI4目录"` 指定游戏路径（用于读取原版图标）。

## 二、界面浏览

- 左侧列表：所有国策树，括号内是焦点数量与来源 mod；
- **滚轮**缩放，**空白处拖动**平移，**适应屏幕**自动缩放；
- 搜索框：按焦点 ID 或名称查找；
- 节点显示图标、ID、名称、花费；箭头 = 前置关系，红色虚线 = 互斥；循环依赖标红；
- 右侧统计：焦点数、前置边、循环、坐标重叠、悬空前置、未保存改动。

## 三、编辑节点

1. 点工具栏「✏️ 编辑模式」；
2. 直接拖动节点修改 x/y（相对定位节点自动换算偏移）；
3. 点击节点打开右侧面板，可修改：
   - X / Y 坐标；
   - 前置：每组一行，组内用 `+` 表示 AND，组之间用 `|` 表示 OR；
   - 互斥（逗号分隔）；
   - 花费（单位：周。cost = 1 即 7 天）；
   - 图标 GFX 名；
   - 中文 / English 名称与描述。
4. 点「保存此节点」「保存名称/描述」写回；首次修改自动生成 `.bak` 备份。

### 撤销 / 重做 / 图标 / 树设置

- **撤销**：`Ctrl+Z` 或工具栏「↶ 撤销」；**重做**：`Ctrl+Y` 或「↷ 重做」；
- 每次写回前会自动存快照，撤销能回退到上一次保存；
- 节点面板「🖼 选择图标」打开图标库，可搜索并点选 GFX 图标；
- 工具栏「⚙ 树设置」可编辑当前国策树的 `country` 块与 `default` 字段（控制哪些国家使用这棵树）。

### 国策效果（completion_reward / select_effect）

- **快捷效果**：面板里直接填数字——政治点、稳定度(%)、战争支持(%)、人力(千)、指挥点、陆军/空军/海军经验，点「保存快捷效果」即可，无需写脚本；
- **一键添加国家精神 / 装备**：填国家精神 id（带下拉提示）或装备 id + 数量，点「添加精神」「添加装备」，自动追加 `add_ideas` / `add_equipment_to_stockpile`；
- 0 或留空表示不添加该项；「清空常见效果」可一键去掉这些常见项；
- 高级需求可展开「高级：直接编辑效果原文」，手动写事件、`add_tech_bonus` 等复杂效果；
- 「选择效果 select_effect」：可选的选中效果，留空即删除该块；
- 保存前会检查花括号是否配平，不匹配会拒绝保存；
- 效果按原文写回，**原脚本注释会丢失**（需要保留注释时请另存备份）。

## 四、批量编辑

| 按钮 | 作用 |
|---|---|
| ➕ 新建节点 | 输入 ID 与坐标，在当前树新建焦点 |
| 🌳 新建树 | 新建立一棵国策树（写入 `common/national_focus/zz_focus_editor_trees.txt`） |
| 🗑 删除树 | 删除当前整棵国策树 |
| 🔗 加前置 / 🔗 加互斥 | 开启后点两个节点即可建立关系 |
| 💾 保存全部 | 一次性写回所有未保存改动 |

## 五、导出覆盖包

点「📦 导出覆盖包」生成 ZIP，只包含改动过的文件。解压后按相同相对路径覆盖到 mod 目录即可，不会影响未编辑的文件。

## 六、国家精神编辑器

左侧边栏「国家精神」→「🧠 国家精神编辑器」：

- 搜索并选择已有国家精神，查看/修改其脚本原文（modifier、picture、allowed 等）；
- 可同时修改中文名称与描述；
- 「＋ 新建精神」：输入 ID 新建国家精神（写入 `common/ideas/zz_focus_editor_ideas.txt`）；
- 「🗑 删除精神」：删除当前选中的国家精神；
- 保存前校验花括号，自动 `.bak` 备份；
- 保存会重写该精神块（块内注释会丢失）。

> 侧边栏「国策树 / 国家精神 / 统计」均可折叠；界面使用低对比暖色深色主题，长时间使用更护眼。

## 七、看板娘「雪绒」

- 以**完整立绘**形式浮在界面上，按住卡片可以拖动到任意位置（拖动时会轻微摇摆）；
- **点击**她会在头顶弹出气泡台词，同时切换一条使用提示（按当前界面语言）；
- 每约 25 秒自动换一条提示；首次打开会先来一句欢迎语；
- 右上角 **⤢** 切换大小，**×** 关闭；
- 位置、大小、显示状态会自动记住，下次打开保持原样；
- 隐藏后点左侧「❄ 雪绒」可重新召唤；
- exe 与窗口图标也使用雪绒头像。

## 八、注意事项

- **每个国家只能有一棵 focus_tree**：给已有国策树的国家新建树不会显示，应把节点加进现有树；
- cost 单位是周：cost = 1 表示 7 天；
- 写回前自动 `.bak`，误操作可手动还原；
- 工具只修改 `common/national_focus` 与本地化文件；
- 界面语言可在右上角切换：中文 / English / 日本語。

## 雪绒衣橱（换装）

- 左侧「❄ 雪绒」打开衣橱面板；
- 目前有 7 套立绘：经典、冬装、运动、花田、教室、咖啡店、雪天；
- 点缩略图立即切换，选择会记住；
- 面板内可「显示雪绒 / 隐藏」；拖动、大小、点击气泡等互动不受影响。

## v0.51 命令面板与快捷键

- `Ctrl+K`（或工具栏最右侧「⌘ 命令」）打开命令面板：一个输入框搜操作命令、国策树、焦点、国家精神、装备、科技、事件；
- `↑ / ↓` 选择，`Enter` 执行，`Esc` 关闭；输入为空时按类别列出常用命令、当前树的焦点和内容条目；
- 快捷键：`Ctrl+S` 保存全部、`Ctrl+Z / Ctrl+Y` 撤销重做、`F` 适应屏幕、`H` 或 `Shift+?` 打开快捷键表；
- 编辑模式下 `Delete` 删除选中节点（仍弹 diff 确认）；`Esc` 关闭右侧面板或退出连线模式；
- 左侧搜索框改成结果列表：列出所有命中的焦点，当前树排前面，点一条即跳转并把节点居中。

## v0.52 配色与解析修复

- 界面颜色全部走设计令牌：纸页主题不再是"雪夜色硬套浅底"，两套主题的正文对比度都达到 WCAG AA（4.5:1）；
- 纸页强调色由 `#8a6a2f` 加深到 `#7c5d24`，大标题在浅底上更清楚；
- 装备/科技列表里的长 id 改为省略号，不再顶破侧栏；
- 修了一个解析老 bug：id 里带 `-` 的装备/科技（如 `tsf_equipment_F-15SE`）之前会被截断成 `15SE`，
  现在是完整 id，装备数从 342 变 348、科技从 676 变 753。

## v0.53 卸载已加载的内容

- 左侧「－ 卸载 mod / 原版」打开已加载列表：每项显示名称、完整路径，以及「可编辑 / 原版 · 只读」标签；
- 点某一行的「卸载」即可从编辑器移除，**只影响当前会话，不删除磁盘文件**；
- 原版参考也能卸：卸掉后国策树/科技/精神只剩你自己 mod 的内容，重新点「📖 加载原版参考」可以再加载；
- 之前这个按钮对原版无效——只读保护把卸载请求也拦了，现在已修。

## v0.54 国策树缩放

- 滚轮缩放改成**以鼠标为中心**：指针指着哪个节点，放大缩小就以它为中心，不再往左上角漂；
- 工具栏新增 `🎯 鼠标缩放 / 🖥 屏幕缩放` 切换（会记住选择）：屏幕模式下缩放以画布中心为基准；
- 缩放百分比实时显示在工具栏（例如 `52%`），滚轮、按钮、适应屏幕都会更新；
- 顺带修了缩放后的坐标换算：以前在 50% 缩放下拖动节点，鼠标移动的距离和节点移动的距离不一致；现在对齐了。

## v0.55 国家中心与项目体检

**国家中心**（侧栏「🌍 国家中心」，或命令面板搜「国家」）

- 左边是所有国家 tag（默认只显示有内容的，117 个里 42 个），带颜色点、树数、州数与问题数；
- 右边一屏摊开这个国家现在有什么：首都 / 执政党 / 政治点 / 稳定与战争支持修正 / 图形文化组 /
  国策树 / 所属州 / 仅核心州 / 开局精神 / 开局科技，以及 history 与定义文件路径；
- 国策树点「打开」直接切过去；精神、科技点一下就打开对应编辑器并选中；
- 有问题的地方直接列在底部（缺 history、缺首都、挂的树不存在、add_ideas 引用了不存在的精神……）。

**项目体检**（工具栏「🩺 体检」，或侧栏「🩺 项目体检」）

- 跨系统引用检查，按「错误 / 警告 / 提示」分级：国策树挂的国家是不是有效 tag、`load_focus_tree` 引用的树存不存在、
  `add_ideas` 引用的精神存不存在、州的 owner / `add_core_of` 是不是有效 tag、事件触发的事件存不存在、本地化键缺不缺；
- 每条带文件名，能跳转的直接跳（树 / 国家 / 精神 / 科技 / 事件），本地化键点一下复制；
- 顶部有筛选项和「语法检查」按钮，旧的括号 / replace_path / namespace 检查还在。

## v0.56 编辑国家历史

国家中心选中一个国家后，点「✏️ 编辑历史」，可以直接改 `history/countries/TAG.txt`：

- 首都（州数字 id）、执政党（democratic / fascism / communism / neutrality）、政治点、稳定度修正、战争支持修正、国策树；
- 开局精神按行填 idea id，清空就是不写这一项；
- 只改你填的字段：注释、`if` 条件块、其它键原样保留，文件的 BOM 和 CRLF 也不动；
- 写入前自动备份（`.bak` + 历史记录，可用「🕘 备份」恢复），写完右侧列出每个字段的「旧值 → 新值」；
- 填了不存在的精神或国策树会提示，但允许先写进去（方便先搭架子后补定义）；
- 国家还没有 history 文件时，保存会自动新建一个 `TAG - 名字.txt`。

## v0.57 州 / 地块

侧栏「🗺 州 / 地块」（或国家中心里点某个州）打开州面板：

- 左边是全部州（默认显示前 400 个，可按 id / 名称 / owner 过滤），显示 owner 与人力；
- 右边一屏给出：所属国家、核心数、人力、州类别、省份数、胜利点数、建筑合计、历史日期；
- 可以直接改：**owner**、**核心（add_core_of，可多个）**、**人力**、**州类别**、**状态级建筑**
  （infrastructure / arms_factory / industrial_complex / dockyard / air_base / anti_air_building / radar_station 等）；
- 只改填写的字段：注释、`history` 日期块、省份子块里的建筑（如 `111 = { naval_base = 1 }`）原样保留；
- 写入前自动备份，保存后列出「旧 → 新」；
- 省份列表与胜利点只读展示，方便对照。

## v0.58 历史编辑器补全 + 省份编辑

**历史编辑器新增**

- **政党支持度**（`set_popularities`）：四个政党各一个数字，留空不改；
- **部队编成 oob**：相对路径字符串；
- **开局科技**（`set_technology`）：每行一个 tech id，整体重建这个块，清空即删除该块；
- 这三项和原来的首都 / 执政党 / 政治点 / 稳定 / 战争支持 / 精神 / 国策树 一起出现在同一个面板里，
  保存后同样列出「旧 → 新」。

**省份编辑**（在「🗺 州 / 地块」里）

- 省份表格：每个省一行，直接改 `naval_base`、`coastal_bunker` 与**胜利点**；
- 建筑填 0 会把该省块删掉，留空表示不改；状态级建筑（infrastructure 等）仍在上面单独编辑；
- 胜利点按「省 id 数值」成对写回，清空全部 = 删掉 `victory_points` 块。
