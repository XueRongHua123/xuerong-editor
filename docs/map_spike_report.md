# 地图编辑器 · 技术验证报告（2026-10-26）

针对「层 1：只读地图预览 + 联动」做的可行性验证，目标是先测出真实数字，再决定技术选型。

## 结论

**可行，成本低于预期。不需要 numpy，只靠 Pillow。包体零增长。**

| 指标 | 实测值 | 备注 |

## 关键发现

1. **不需要 numpy**。纯 Python 遍历 11.5M 像素只要 1.33 s，因为瓶颈是 Pillow 的 `tobytes()` 与 dict 查表，不是算术。引入 numpy 只会让包体多 15 MB，收益不到 1 秒。
2. **Pillow 早就在包里**（`focus_editor.py` 的图标与皮肤处理已经在用），所以地图功能让 exe 从 24.2 MB 变成…… 还是 24.2 MB。
3. **点击取省用「id 编码图」最省事**：把省 id 拆成 RGB 三通道，前端 `getImageData(1,1)` 直接还原成 id，不需要 13K 项颜色映射表。
4. **整幅 PNG 叠图 + CSS transform 缩放**足够流畅（61 FPS），不需要瓦片切片。

## 已落地的实现（v0.71）

- 后端 `map_meta` / `map_build` / `map_asset`：按 `provinces.bmp` 的 mtime+size 做缓存键，源文件变了自动重建
- 前端「🗺 地图」面板：四层图（底图 / 省色 / 州 / 省界）+ 图层开关 + 透明度、滚轮以光标为中心缩放、拖动平移、适应
- 悬停显示「省 N · 州 M」，单击写入联动目标，**双击直接打开对应州面板**
- 搜索框输省号定位到质心（1.1 倍），输州号定位到该州所有省份的质心平均位置
- 省色用 6 色循环 + 按 id 的明度扰动：相邻省不撞色，整体协调
