# 功能能力与实测范围说明

本页面向 HOI4 mod 作者说明「雪绒的钢铁雄心编辑器」各项能力的当前可靠程度、实机测试范围与已知局限。内容全部基于实测结果，未验证项均如实标注。

## 验证尺度说明

下表采用四项客观指标衡量每个编辑域的完成度：

1. **可读且写回一致**：界面能正常加载并展示已有 mod 内容；修改保存后重新读回，数据与输入完全一致，且不会写穿只读的父 mod 或游戏原版目录。
2. **静态格式校验**：写出的文件符合 HOI4 语法规范，包括花括号配平、仅 `localisation/*.yml` 保留 UTF-8 BOM（其余脚本无 BOM）、引用关系与 `replace_path` 可正常解析。
3. **实机启动主菜单零新增报错**：在真实《钢铁雄心 IV》（`hoi4.exe`）客户端中加载并启动至主菜单，将 `error.log` 与「仅加载依赖父层」的基线对比，确认新增报错为 **0 条**。
4. **局内对局实机截图复核**：启动具体国家进入地图对局画面，通过人眼与截图确认改动已在游戏中生效。

> **测试覆盖的真实环境**：
> - 《钢铁雄心 IV》纯原版
> - 大型中文剧情向改档（含大量自定义国策、事件、决议、地图与本地化）
> - Kaiserreich（`1521695605`，大型架空历史全面改档）
> - Millennium Dawn（`3374271790`，大型现代战争机制改档，结构复杂且覆盖海量体系）
> - The New Order / TNO（`2438003901`，共享国策与事件体量极大、意识形态高度自定义）

## 为什么局内对局截图目前标为「待补充」

自动化流程已可在非交互环境下完成「启动 `hoi4.exe` 至主菜单并采集 `error.log`」的全量差分验证，但进入具体国家开局并截取局内画面需要完整的前台交互桌面会话支持。因此在主菜单 `error.log` 零新增的基础上，各编辑域的局内开局截图仍在逐项人工补齐中。

如果你在具体国家开局后发现某一功能写出的数据在游戏内表现异常，欢迎通过界面右上或诊断面板的 `📦 导出诊断包` 获取 `xuerong-diag.zip` 并提交 Issue 反馈。
