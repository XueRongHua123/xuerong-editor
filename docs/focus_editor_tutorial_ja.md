# 国家方針ツリーエディタ · チュートリアル

HOI4 の国家方針ツリーを閲覧・編集するローカルツールです。mod ファイルを直接読み書きし、パッチ ZIP を出力できます。

## 1. 起動

- exe をダブルクリック（または `python focus_editor.py`）。
- 先にエディタ画面が開きます。ウェルカム画面の「mod フォルダを選択」でページ内フォルダブラウザが開き、フォルダを移動するかパスを貼り付けて「选择此文件夹」を押します。
- 後からサブ mod を追加する場合は、左サイドバーの「＋ mod を追加」をクリックします（後に読み込んだ方が同じツリー ID を上書き）。

### 新しい mod を作成（バニラをベースに）

左サイドバーの「🆕 新しい mod」：

- mod フォルダ名、表示名、バージョン、ゲームバージョンを入力；
- 「サンプル国家方針ツリーを作成」にチェックすると、ツリー ID と国家 TAG を指定できます；
- `descriptor.mod`、サンプル国家方針ツリー（`common/national_focus`）、中国語/英語ローカライズを生成；
- 保存先が HOI4 の `mod` フォルダなら、ランチャー用 `.mod` ファイルも自動作成；
- 作成後は自動的に読み込まれます。バニラのファイルは置き換えないため、バニラに追加する形の mod に向いています。
- 本体 + サブ mod を同時に読み込む場合：

```
FocusTreeEditor.exe --mod "本体フォルダ" --mod "サブフォルダ"
```

後に指定した mod が同じツリー ID を上書きします（ゲーム内の読み込み順と同じ）。

任意：`--port 8765`、`--game "HOI4 インストール先"`（バニラアイコン用）。

## 2. 閲覧

- 左の一覧：全ツリー（ノード数と読み込み元 mod 付き）。
- **ホイール**でズーム、**空白をドラッグ**で移動、「画面に合わせる」で自動調整。
- 検索欄でノード ID / 名前を検索。
- ノードにはアイコン・ID・名前・コストを表示。矢印 = 前提、赤い破線 = 排他、循環は赤表示。
- 統計：ノード数、前提エッジ、循環、座標重複、存在しない前提、未保存の変更。

## 3. ノード編集

1. 「編集モード」をオン。
2. ノードをドラッグして x/y を変更（相対指定ノードは自動換算）。
3. ノードをクリックすると右パネルが開きます：
   - X / Y 座標；
   - 前提：`|` でグループ、`+` で AND；
   - 排他（カンマ区切り）；
   - コスト（単位は週。cost = 1 で 7 日）；
   - アイコン GFX 名；
   - 中国語 / 英語の名前と説明。
4. 「ノード保存」「名前/説明を保存」で書き込み。初回変更時に `.bak` が作成されます。

### 元に戻す / やり直し / アイコン / ツリー設定

- **元に戻す**：`Ctrl+Z` または「↶ 元に戻す」；**やり直し**：`Ctrl+Y` または「↷ やり直し」；
- 書き込み前にスナップショットを保存するため、直前の保存状態まで戻せます；
- ノードパネルの「🖼 アイコンを選択」でアイコン一覧を開き、検索して選択；
- ツールバーの「⚙ ツリー設定」で現在のツリーの `country` ブロックと `default` を編集できます（どの国が使うか）。

### 国策効果（completion_reward / select_effect）

- **クイック効果**：パネルに数値を入力するだけ——政治ポイント、安定度(%)、戦争支持(%)、人的資源(千)、指揮ポイント、陸軍/空軍/海軍経験値——「クイック効果を保存」で反映。スクリプト不要；
- **国家精神 / 装備をワンクリック追加**：国家精神 ID（候補表示あり）または装備 ID + 数量を入力し、「精神を追加」「装備を追加」で `add_ideas` / `add_equipment_to_stockpile` を自動追加；
- 0 または空欄は追加なし。「一般効果をクリア」で一括削除；
- 上級者は「上級：効果の原文を編集」でイベントや `add_tech_bonus` などを直接記述；
- 「選択効果 select_effect」：選択時の任意効果。空欄でブロック削除；
- 保存前に括弧の対応を検査し、不一致なら保存しません；
- 効果は原文で書き戻すため、**スクリプト内のコメントは失われます**（必要な場合はバックアップしてください）。

## 4. 一括編集

| ボタン | 動作 |
|---|---|
| ＋ 新規ノード | 現在のツリーにノードを追加 |
| 新規ツリー | 新しい国家方針ツリーを作成（`common/national_focus/zz_focus_editor_trees.txt`） |
| ツリー削除 | 現在のツリーを削除 |
| 前提を追加 / 排他を追加 | 2 つのノードをクリックして関係を作成 |
| すべて保存 | 未保存の変更をまとめて書き込み |

## 5. 出力

「パッチ出力」で変更ファイルだけの ZIP を作成します。mod フォルダの同じ相対パスに上書きしてください。

## 6. 国家精神エディタ

左サイドバー「国家精神」→「🧠 国家精神エディタ」：

- 既存の国家精神を検索・選択し、スクリプト原文（modifier、picture、allowed など）を閲覧・編集；
- 中国語の名前と説明も編集可能；
- **＋ 新規精神**：ID を入力して国家精神を作成（`common/ideas/zz_focus_editor_ideas.txt` に書き込み）；
- **🗑 精神削除**：選択中の国家精神を削除；
- 保存前に括弧を検査し、`.bak` を自動作成；
- 保存すると精神ブロックを書き換えます（ブロック内コメントは失われます）。

> サイドバーの「国家方針 / 国家精神 / 統計」は折りたたみ可能。低コントラストの暖色ダークテーマで目に優しい表示です。

## 7. マスコット「雪絨（シュエロン）」

- **全身イラスト**のカードとして画面に浮かび、ドラッグでどこへでも移動できます（ドラッグ中は少し揺れます）；
- **クリック**で頭上の吹き出しに台詞が出て、使用ヒントも切り替わります（現在の UI 言語）；
- 約 25 秒ごとにヒントが自動で切り替わり、初回起動時は挨拶を表示；
- 右上 **⤢** でサイズ切替、**×** で閉じる；
- 位置・サイズ・表示状態は記憶されます；
- 閉じた後はサイドバーの「❄ 雪絨」で呼び戻せます；
- exe とウィンドウのアイコンも彼女のアバターです。

## 8. 注意

- HOI4 は **1 国につき 1 つの focus_tree** のみ。既存ツリーがある国に新規ツリーを作っても表示されません。既存ツリーにノードを追加してください。
- cost の単位は週：cost = 1 は 7 日。
- 書き込み前に `.bak` を作成します。必要なら手動で復元してください。
- 変更するのは `common/national_focus` とローカライズのみです。
- UI 言語は右上で切替：中文 / English / 日本語。

## 雪絨ワードローブ（着せ替え）

- 左の「❄ 雪絨」でワードローブが開きます；
- 7 着：クラシック、冬服、スポーツ、花畑、教室、カフェ、雪の日；
- サムネイルをクリックで即切り替え、選択は記憶されます；
- パネル内で表示/非表示も可能。ドラッグ・サイズ・吹き出しはそのまま使えます。
