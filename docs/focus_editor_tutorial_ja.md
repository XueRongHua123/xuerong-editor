# 国家方針ツリーエディタ · チュートリアル

HOI4 の国家方針ツリーを閲覧・編集するローカルツールです。mod ファイルを直接読み書きし、パッチ ZIP を出力できます。

## 1. 起動

- exe をダブルクリック（または `python focus_editor.py`）。
- 先にエディタ画面が開きます。ウェルカム画面の「mod フォルダを選択」でページ内フォルダブラウザが開き、フォルダを移動するかパスを貼り付けて「选择此文件夹」を押します。
- 後からサブ mod を追加する場合は、左サイドバーの「＋ mod を追加」をクリックします（後に読み込んだ方が同じツリー ID を上書き）。

### 新しい mod を作成（バニラをベースに）

左サイドバーの「🆕 新しい mod」：

- mod フォルダ名、表示名、バージョン、ゲームバージョンを入力；
- 「サンプル国家方針ツリーを作成」にチェックすると、ツリー ID と国家 TAG を指定できます；
- `descriptor.mod`、サンプル国家方針ツリー（`common/national_focus`）、中国語/英語ローカライズを生成；
- 保存先が HOI4 の `mod` フォルダなら、ランチャー用 `.mod` ファイルも自動作成；
- 作成後は自動的に読み込まれます。バニラのファイルは置き換えないため、バニラに追加する形の mod に向いています。
- 本体 + サブ mod を同時に読み込む場合：

```
FocusTreeEditor.exe --mod "本体フォルダ" --mod "サブフォルダ"
```

後に指定した mod が同じツリー ID を上書きします（ゲーム内の読み込み順と同じ）。

任意：`--port 8765`、`--game "HOI4 インストール先"`（バニラアイコン用）。

## 2. 閲覧

- 左の一覧：全ツリー（ノード数と読み込み元 mod 付き）。
- **ホイール**でズーム、**空白をドラッグ**で移動、「画面に合わせる」で自動調整。
- 検索欄でノード ID / 名前を検索。
- ノードにはアイコン・ID・名前・コストを表示。矢印 = 前提、赤い破線 = 排他、循環は赤表示。
- 統計：ノード数、前提エッジ、循環、座標重複、存在しない前提、未保存の変更。

## 3. ノード編集

1. 「編集モード」をオン。
2. ノードをドラッグして x/y を変更（相対指定ノードは自動換算）。
3. ノードをクリックすると右パネルが開きます：
   - X / Y 座標；
   - 前提：`|` でグループ、`+` で AND；
   - 排他（カンマ区切り）；
   - コスト（単位は週。cost = 1 で 7 日）；
   - アイコン GFX 名；
   - 中国語 / 英語の名前と説明。
4. 「ノード保存」「名前/説明を保存」で書き込み。初回変更時に `.bak` が作成されます。

### 元に戻す / やり直し / アイコン / ツリー設定

- **元に戻す**：`Ctrl+Z` または「↶ 元に戻す」；**やり直し**：`Ctrl+Y` または「↷ やり直し」；
- 書き込み前にスナップショットを保存するため、直前の保存状態まで戻せます；
- ノードパネルの「🖼 アイコンを選択」でアイコン一覧を開き、検索して選択；
- ツールバーの「⚙ ツリー設定」で現在のツリーの `country` ブロックと `default` を編集できます（どの国が使うか）。

### 国策効果（completion_reward / select_effect）

- **クイック効果**：パネルに数値を入力するだけ——政治ポイント、安定度(%)、戦争支持(%)、人的資源(千)、指揮ポイント、陸軍/空軍/海軍経験値——「クイック効果を保存」で反映。スクリプト不要；
- **国家精神 / 装備をワンクリック追加**：国家精神 ID（候補表示あり）または装備 ID + 数量を入力し、「精神を追加」「装備を追加」で `add_ideas` / `add_equipment_to_stockpile` を自動追加；
- 0 または空欄は追加なし。「一般効果をクリア」で一括削除；
- 上級者は「上級：効果の原文を編集」でイベントや `add_tech_bonus` などを直接記述；
- 「選択効果 select_effect」：選択時の任意効果。空欄でブロック削除；
- 保存前に括弧の対応を検査し、不一致なら保存しません；
- 効果は原文で書き戻すため、**スクリプト内のコメントは失われます**（必要な場合はバックアップしてください）。

## 4. 一括編集

| ボタン | 動作 |
|---|---|
| ＋ 新規ノード | 現在のツリーにノードを追加 |
| 新規ツリー | 新しい国家方針ツリーを作成（`common/national_focus/zz_focus_editor_trees.txt`） |
| ツリー削除 | 現在のツリーを削除 |
| 前提を追加 / 排他を追加 | 2 つのノードをクリックして関係を作成 |
| すべて保存 | 未保存の変更をまとめて書き込み |

## 5. 出力

「パッチ出力」で変更ファイルだけの ZIP を作成します。mod フォルダの同じ相対パスに上書きしてください。

## 6. 国家精神エディタ

左サイドバー「国家精神」→「🧠 国家精神エディタ」：

- 既存の国家精神を検索・選択し、スクリプト原文（modifier、picture、allowed など）を閲覧・編集；
- 中国語の名前と説明も編集可能；
- **＋ 新規精神**：ID を入力して国家精神を作成（`common/ideas/zz_focus_editor_ideas.txt` に書き込み）；
- **🗑 精神削除**：選択中の国家精神を削除；
- 保存前に括弧を検査し、`.bak` を自動作成；
- 保存すると精神ブロックを書き換えます（ブロック内コメントは失われます）。

> サイドバーの「国家方針 / 国家精神 / 統計」は折りたたみ可能。低コントラストの暖色ダークテーマで目に優しい表示です。

## 7. マスコット「雪絨（シュエロン）」

- **全身イラスト**のカードとして画面に浮かび、ドラッグでどこへでも移動できます（ドラッグ中は少し揺れます）；
- **クリック**で頭上の吹き出しに台詞が出て、使用ヒントも切り替わります（現在の UI 言語）；
- 約 25 秒ごとにヒントが自動で切り替わり、初回起動時は挨拶を表示；
- 右上 **⤢** でサイズ切替、**×** で閉じる；
- 位置・サイズ・表示状態は記憶されます；
- 閉じた後はサイドバーの「❄ 雪絨」で呼び戻せます；
- exe とウィンドウのアイコンも彼女のアバターです。

## 8. 注意

- HOI4 は **1 国につき 1 つの focus_tree** のみ。既存ツリーがある国に新規ツリーを作っても表示されません。既存ツリーにノードを追加してください。
- cost の単位は週：cost = 1 は 7 日。
- 書き込み前に `.bak` を作成します。必要なら手動で復元してください。
- 変更するのは `common/national_focus` とローカライズのみです。
- UI 言語は右上で切替：中文 / English / 日本語。

## 雪絨ワードローブ（着せ替え）

- 左の「❄ 雪絨」でワードローブが開きます；
- 7 着：クラシック、冬服、スポーツ、花畑、教室、カフェ、雪の日；
- サムネイルをクリックで即切り替え、選択は記憶されます；
- パネル内で表示/非表示も可能。ドラッグ・サイズ・吹き出しはそのまま使えます。

## v0.51 コマンドパレットとショートカット

- Ctrl+K（またはツールバー右端の「コマンド」）でコマンドパレットを開きます。1 つの入力欄で操作コマンド・国家方針ツリー・方針・国家精神・装備・技術・イベントを検索できます。
- 矢印キーで選択、Enter で実行、Esc で閉じます。入力が空のときはカテゴリ別によく使うコマンド、現在のツリーの方針、コンテンツ項目を表示します。
- ショートカット：Ctrl+S すべて保存、Ctrl+Z / Ctrl+Y 元に戻す・やり直し、F 画面に合わせる、H または Shift+? でショートカット一覧。
- 編集モードでは Delete で選択中の方針を削除（diff 確認は残ります）。Esc で右パネルを閉じる／リンクモードを解除します。
- サイドバーの検索は結果一覧になりました。該当する方針をすべて表示し（現在のツリーが先頭）、クリックするとその方針へ移動して中央に表示します。

## v0.52 配色とパーサ修正

- 画面の色をすべてデザイントークン化し、紙テーマ（明るい背景）でも本文のコントラストが WCAG AA（4.5:1）に達します。
- 紙テーマのアクセント色を #8a6a2f から #7c5d24 に濃くし、大きな見出しの可読性を上げました。
- 装備・技術リストの長い id は省略記号で切り、サイドバーを突き抜けないようにしました。
- パーサの不具合修正：`-` を含む id（例 `tsf_equipment_F-15SE`）が `15SE` に切れていました。
  装備 342→348、技術 676→753 に増えます。

## v0.53 読み込み済みの解除

- 左の「－ mod / バニラを解除」で読み込み済み一覧を開きます。名前・フルパス・「編集可 / バニラ・読み取り専用」タグを表示します。
- 各行の「解除」でエディタから外れます。**現在のセッションだけに影響し、ファイルは削除しません**。
- バニラ参考も解除できます。解除後は自分の mod の内容だけになり、「バニラ参考を読み込む」で戻せます。
- 以前は読み取り専用ガードが解除リクエストまで止めていたため、バニラは解除できませんでした。

## v0.54 国家方針ツリーのズーム

- ホイールズームを**マウス中心**に変更しました。ポインタの下にあるノードが動かず、左上へ流れません。
- ツールバーに `マウスズーム / 画面ズーム` の切り替えを追加（選択は記憶されます）。画面ズームはキャンバス中心が基準です。
- ズーム率をツールバーに常時表示（例 `52%`）。ホイール・ボタン・フィットで更新されます。
- ズーム後の座標計算も修正：50% 表示でドラッグしたとき、マウスの移動量とノードの移動量がずれていました。

## v0.55 国家ハブとプロジェクト点検

**国家ハブ**（サイドバー「国家ハブ」、コマンドパレットで「国家」）

- 左：すべての国家タグ（既定では中身のあるものだけ、117 中 42）。色ドット・ツリー数・州数・問題数を表示。
- 右：その国が今持っているものを 1 画面に——首都、与党、政治力、安定度/戦争支持の修正、グラフィック文化、
  国家方針ツリー、所有州、中核州のみ、開始精神、開始技術、history と定義ファイルのパス。
- ツリーの「開く」でそのツリーへ移動。精神・技術のチップを押すと該当エディタで選択されます。
- 構造的な問題は下部に一覧（history 無し、首都未設定、存在しないツリー参照、add_ideas の参照切れなど）。

**プロジェクト点検**（ツールバー「点検」）

- エラー / 警告 / 情報に分類した横断参照チェック：ツリーの国家タグ、load_focus_tree の参照先、
  add_ideas の参照先、州の owner と add_core_of、存在しないイベントの呼び出し、ローカライズ欠落。

## v0.56 国家史の編集

国家ハブで国を選び「史を編集」を押すと `history/countries/TAG.txt` を直接編集できます。

- 首都（州 id）、与党、政治力、安定度・戦争支持の修正、国家方針ツリー；
- 開始精神は 1 行 1 id。空にするとその項目は書きません；
- 入力した項目だけを変更し、コメント・`if` ブロック・他のキーはそのまま。BOM と CRLF も維持します；
- 書き込み前にバックアップ（`.bak` と履歴）。保存後に各項目の「旧 → 新」を表示します；
- 存在しない精神・ツリーは警告を出しますが書き込みは可能です；
- history ファイルが無い国は、保存時に `TAG - 名前.txt` を新規作成します。

## v0.57 州

サイドバー「州」（または国家ハブで州をクリック）で開きます。

- 左：全州（先頭 400 件、id / 名前 / owner で絞り込み）。owner と人力を表示。
- 右：所属国、中核数、人力、州カテゴリ、州数、勝利点、建築合計、歴史日付。
- 編集できる項目：**owner**、**中核（add_core_of、複数可）**、**人力**、**州カテゴリ**、**州レベルの建築**
  （infrastructure / arms_factory / air_base など）。
- 入力した項目だけを書き換えます。コメント、`history` の日付ブロック、州単位の建築ブロック
  （例 `111 = { naval_base = 1 }`）はそのまま残ります。
- 書き込み前にバックアップし、保存後に「旧 → 新」を表示します。
