## 雪绒的钢铁雄心编辑器 v1.10.0

铁路能看了。新增「铁路」预设，地图上用折线画出全部铁路，断连的标红。

### 数据

`map/railways.txt` 两种写法都认：

```
行式  <等级> <省数> p1 p2 p3 ...
块式  railway = { level = N provinces = { p1 p2 ... } }
```

muvluvCN 的 railways.txt 是行式，1661 条。

### 可视化

预设栏多了「铁路」：

```
预设   [地形] [州] [省色块]
       [政治] [战略区] [原始]
       [铁路]
```

- 黄色折线 = 正常铁路，线宽按等级（1 级细，5 级粗）
- **红色 = 断连**（相邻两省不接壤）
- 线宽随缩放自适应，缩到 18% 时压细，不会糊成一片

实测 muvluvCN：**1661 条铁路，17 条断连，0 条等级超 5**。

### 两个性能坑

**邻接检查从 5 小时降到 3.7 秒**

`map_prov_neighbors` 是按单个省算的、每次整幅扫描 5 秒。铁路要查几千段，逐段调用会跑到天荒地老。

新增 `_all_prov_neighbors`：一次扫描建全图邻接表，按 bmp mtime 缓存。

**低缩放不画省界**

13264 个省在 18% 缩放下每省只有几个像素，边界会挤成一整片白网。

现在 `k < 0.42` 时跳过省界绘制（铁路照画）。要看边界就放大，或者切到其它预设。

### 与矢量边界的共存

两个都要画在 `mapEdgeCanvas` 上。第一版分开画，结果边界那一步的 `clearRect` 把铁路擦掉了。

改成同一次绘制：先画边界，再在同一个 `ctx` 上叠铁路。
