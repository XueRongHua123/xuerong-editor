## 雪绒的钢铁雄心编辑器 v1.21.1

开局部队的**地图可视化**。

### 新增图层 units.png

在省份图上按省画标记：

- 位置：省中心（来自 `centers.json`）
- 半径随部队数增长：<5 / <20 / <50 / 更多
- 颜色：红底白边，里面写部队数（100 以上显示 `99+`）

实测（原版 + 测试 mod 链）：**1304 个省有部队**。

### 界面

地图页图层列表多一个「开局部队」勾选框，勾上后叠在任意图层之上。

### 省面板

点省后显示该省的开局部队列表：

```
开局部队
  战术机联队              A-Target
  战术机联队              A-Target
  …
```
