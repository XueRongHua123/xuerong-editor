## 雪绒的钢铁雄心编辑器 v0.79.0

政治视图：没有颜色定义的国家不再显示为统一灰色。

### 背景

HOI4 的国家颜色写在 `common/countries/<文件>.txt` 的 `color = ...` 里。但很多第三方 mod 会在
`common/country_tags/` 里把大量 tag 指向共享文件，而这些共享文件只写 `graphical_culture`，不写颜色。

以 workshop `2438003901` 为例：512 个 tag 中有 **451 个（88%）** 指向不含 color 的文件，
原版也没有对应定义。旧逻辑对这类国家统一使用灰色，导致政治视图几乎整图一色。

### 现在的取色顺序

1. mod 的 `def_file` 里的 `color`（支持 `{ r g b }` / `rgb { }` / `hsv { }`）
2. 原版同名文件里的 `color`
3. 以上都没有 → 按 tag 的 CRC32 派生一个稳定色（HSV 色相 0–1，饱和度 0.45，明度 0.78）

派生色保证：同一 tag 每次结果一致、不同 tag 不撞色、不会出现大片灰。

### 实测（workshop 2438003901）

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 政治层不同颜色数 | 6 | **266** |
| 统一 fallback 灰 | 31.9% | **0%** |
| 意大利 | 灰 | 绿（67 127 63 系，来自原版定义） |

67% 的深灰是海域与未归属州省，属于正常。

### 需要说明的一点

第 3 步的派生色**不是游戏内原色**。这些国家在原版与 mod 里都没有显式 color，
游戏运行时同样由引擎兜底，编辑器无法从文件还原其真实配色。
派生色的作用是在编辑器里让每个国家可辨识；如果你需要与游戏严格一致，
可以在 `common/countries/` 里给这些 tag 补上 `color` 定义，编辑器会自动采用。

### 验证

- 该 mod：州归属解析正确（ITA / GER / VYT / BRA），政治层 266 色，无统一灰
- muvluvCN：BETA 巢穴区域保持黑色，有定义的国家颜色不变
