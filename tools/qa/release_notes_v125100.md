# 雪绒的钢铁雄心编辑器 v1.25.1

## 本次改了什么

> **小更新**｜完善初次上手引导、游戏目录设置与脱敏诊断包导出

这版重点打磨第一次打开编辑器时的上手路径和遇到报错后的自助排查能力：没自动识别出游戏目录时可以直接在网页里选定并记住，遇到异常能一键导出不含隐私与脚本正文的诊断包方便定位或提 Issue。

## 一、首次上手与游戏目录设置

- **欢迎页与侧栏新增游戏目录状态条**：打开欢迎页或查看左侧「数据源」即可一眼看到《钢铁雄心 IV》安装目录是否就绪；自动探测失败时，点击「📁 选择游戏目录」就能在弹窗中浏览定位（带 `HOI4` 标记）或直接粘贴路径保存，下次启动自动记住。
- **文件夹选择器修复**：输入或粘贴路径后可直接点击确定生效，不再必须先按回车；同时修掉快速输入路径时被后台目录列表覆盖回去的偶发问题。
- **新建 Submod 防误建示例树**：在「新建模组」选择依赖父 mod 时，默认取消勾选「创建示例国策树」，避免新手无意间多出一棵空示例树覆盖通用国策；若手动填写了国策树 ID 或国家 TAG，会自动联动重新勾上。
- **首次引导步骤同步新版功能**：左下角引导流最后两步已更新为直接跳转到「🎮 进游戏检查」与「📦 打包发布」。

## 二、出错自助与脱敏诊断包

- **一键导出脱敏诊断包**：在欢迎页底部、左侧「🩺 诊断」面板顶栏及报错提示卡片中均可点击「📦 导出诊断包」下载 `xuerong-diag.zip`（汇总编辑器版本、叠加链统计、当前模组诊断条目和最近服务端报错日志）。
- **自动隐私脱敏**：生成诊断包时会自动把系统用户名、用户主目录路径以及常见 API Key/Bearer/密码字段替换为 `<USER>` 或 `<REDACTED>`，且绝不读取任何 mod 脚本正文或 `ai_config.json`。
- **报错提示不再只有一句话**：为「缺少游戏目录」「找不到国家」「参数不合法」「读取失败」「写入失败」「服务器内部出错」等报错提示卡片补齐了下一步操作按钮，可直接点开设置游戏目录、查看叠加链、打开诊断、重加载数据或导出诊断包。

## 三、文档与反馈支持

- 公开仓库同步更新主页定位，补充了十分钟新建 Submod 上手教程、各编辑域实测能力边界说明，以及 GitHub Bug/功能建议表单模板。
