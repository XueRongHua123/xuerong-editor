## 雪绒的钢铁雄心编辑器 v1.12.1

地形编辑补齐三项：批量改、按类型全改、画笔。

### 1. 批量改

在地图上拖框选中多个省（`MAP.sel` 数组），点「把上面选的地形应用到已选」。

实测 3 个省改成 desert，168 像素。

批量走的是**一次读全图、一次写全图**，不是逐省循环——改几百个省也只读写一次磁盘。

### 2. 按类型全改

两个下拉：源类型 → 目标类型。

实测把 1020 个 forest 改成 jungle，耗时 **4.1 秒**（含读 csv、扫像素、写 bmp）。

### 3. 画笔

编辑页底部「地形笔刷」：

```
[开启笔刷]  [====|====] 5
```

开启后在地图上按住左键拖动，抬手保存。笔刷是**圆形**（按半径判定），大小 1–30 像素。

实测刷两个点（笔刷 5）改 162 个像素，耗时 **14 毫秒**。

画笔有个特殊之处：**只改 terrain.bmp，不动 definition.csv**。因为它改的是像素级地形，
而 definition.csv 的一条记录代表整个省——两者粒度不同。所以刷完之后该省的「主地形」不变，
但地图上看到的颜色变了。

### 一个写入坑

`Image.save()` 在项目路径上会报 `OSError: Invalid argument`（它内部用 `w+b` 重开文件）。

改成和 `bmp_write_rect_8` 一样的做法：`open(path, "r+b")` + 逐点 seek 写单字节。

### 界面

编辑页从上到下：

```
地形         plains
改地形
[forest (1020)]  [应用]

批量
已选 3 个省
[把上面选的地形应用到已选]
按类型全改
[jungle] → [plains]  [转换]

地形笔刷
[开启笔刷]  [====|====] 5
```

批量、按类型、画笔三种操作完成后都会自动重建图层并强制重载图片。
