## 雪绒的钢铁雄心编辑器 v1.9.3

预设现在会绑定左键点选的对象——看什么视图，点出来就是什么。

### 之前的问题

不管切到哪个视图，左键点下去永远选中「省」，右侧永远显示省的属性。

在政治视图上点到某国的一块地，得到的是「省 13063 · 州 809」，还得自己去查这是哪个国家。

### 现在

| 预设 | 左键点选 | 右侧显示 |
|---|---|---|
| 地形 | 省 | 省属性（原样） |
| **州** | **州** | 州 ID、名字、省数、归属国、胜利点 |
| 省色块 | 省 | 省属性（原样） |
| **政治** | **国家** | 国家 TAG、名字 |
| **战略区** | **战略区** | 战略区 ID、名字 |
| 原始 | 省 | 省属性（原样） |

实测点同一块地（省 13063）：

```
省视图   → 省 13063 · 州 809 · 战略区 220 · 14,148 像素
州视图   → 州 809 泽姆加里 · 省数 6 · 归属国 SOV
政治视图 → SOV 泽姆加里
战略区   → 战略区 220
```

### 实现细节

- 预设定义里加了 `unit` 字段（`prov` / `state` / `country` / `region`）
- `mapShowOps` 被包了一层：非省模式先解析出对应的州/国家/战略区，替换右侧面板
- 省模式**完全走原逻辑**，不拦截（拦截会让其它预设的旧内容残留）

### 一个数据结构上的坑

前端没有全局 `STATES`，州数据是按需拉 `/api/states` 的。所以第一次点州/国家时要等一次请求（约 100ms），之后缓存。

另外 `/api/states` 返回里的 `provinces` 字段有时是数组、有时是数量，两种都做了兼容。

### 待补

- 国家信息目前只有 TAG 和名字，首都、政治点还没接（要另外拉 `/api/countries`）
- 州/国家视图下还不能直接编辑（改 owner、加省）
