## 雪绒的钢铁雄心编辑器 v1.0.3

**一键更新**：在编辑器里点一下，新版下载并解压到旁边，关掉旧窗口从新目录启动就行。

### 为什么不是"自动替换自己"

我先做了「退出 → 替换 exe → 重启」的版本，实测下来问题很多：

- Windows 下运行中的 exe 被占用，替换要靠 bat 脚本轮询等进程退出
- 脚本在不同权限/中文路径/打包环境下的行为不一致
- 失败时可能留下一个坏 exe

对一个 20 MB 的单文件程序来说，**为了省下"换一个目录启动"这一步，去冒损坏 exe 的风险，不划算**。

### 现在的做法

点「下载并解压新版」后：

1. 从 GitHub 拉最新 zip（约 20 MB）
2. 解压到当前 exe 旁边的 `_update_<版本号>/` 目录
3. 弹窗告诉你解压到了哪里
4. 关掉当前窗口，从新目录双击启动即可

**当前版本一个字节都不会被改动**，解压失败也只是白下载一次。

### 实测

```
旧版本: 1.0.3
下载目标: xuerong-editor-v1.0.2.exe 20.1 MB
下载并解压: ok=True version=1.0.2 size=19.9
解压目录: work\_update_1.0.2\雪绒的钢铁雄心编辑器_v1.0.2
exe 存在: True（20.1 MB）
```

### 另外修了一个真 bug

`cache/update.json` 和 `cache/update_pkg/` 之前用错了变量（`W` 而不是 `WORK`）。
`W` 在 exe 模式下指向 PyInstaller 的临时解压目录，**每次启动都不一样、退出即删**——
意味着更新缓存写进去就没了，下载的包也会随进程消失。

这就是第一版一键更新"下载成功但找不到文件"的真正原因。

### 顺带

更新弹窗的按钮从「下载新版」（跳到 GitHub）改成「下载并解压新版」（留在应用内完成）。
