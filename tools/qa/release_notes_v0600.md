## 雪绒的钢铁雄心编辑器 v0.60.0

把"数据源"从国策树里搬出来，放到侧栏最上面，并给所有需要读盘的操作配了进度。

### 变化

- **侧栏顶部新增「数据源」区块**（带描边、放最显眼的位置）：
  - ＋ 添加 mod（选模组根目录）
  - － 卸载（移除已加载项）
  - 📖 加载原版参考 / 🚫 卸载原版参考（按钮随状态自动切换）
  - 🆕 新建模组
  - 右上角徽标显示已加载数量，底部一行写清"现在是哪几个 mod 加载着"
- 国策树折叠组里不再挤这些按钮，只剩搜索框和树列表。
- **加载进度**：顶部 4px 流光进度条 + 面板内转圈 + 实时秒数（例如 `正在加载 mod… 12.4s`），
  覆盖"添加 mod / 加载原版 / 卸载"三条路径；`/api/data` 返回后自动停表并把状态行改成"xx 已加载"。
  原版参考首次加载会扫描图标，进度条能明确告诉你没卡死。

### 为什么加秒表

加载大 mod 时要扫几千个图标，界面会静住几十秒。只放一个转圈容易让人以为崩了，带秒数至少能看出它在动。
