## 雪绒的钢铁雄心编辑器 v1.9.4

两件事：州视图下双击能下钻到省；撤销备份从 31.9 MB 降到 1.3 KB。

### 1. 州视图下双击下钻到省

州视图单击仍然是选州（改 owner 用），但**双击会下钻到省**：

```
单击 → 州 809 泽姆加里 · 省数 6 · 归属国 SOV
双击 → 省 13063 · 州 809 · 14,148 像素（并自动打开省色块图层）
```

政治、战略区视图同理。这样既保留「整块看」的能力，也不丢掉「精确到某一块地」的能力。

### 2. 撤销备份：包围盒 → 点级

十字交叉修复改动 173 个散布全图的像素，原来按包围盒备份，一次存 5490×2034×3 = **31.9 MB**。

改成只存「像素索引 + 原 RGB」：

```
4 字节索引 + 3 字节颜色 = 7 字节/像素
173 个像素 ≈ 1.3 KB
```

实测：修复 179 处十字交叉，备份文件 **1215 字节**（原来 31.9 MB），撤销后 md5 完全恢复。

### 一个逻辑错误

第一版把 4 轮迭代各记成一个 undo 条目，撤销时只弹出最后一个 → 只恢复 1 个像素。

现在所有轮次共享一个「原始值字典」（同像素只记第一次的原值），最后合成**一条** undo 记录，一次撤销回到修复前。

### 点级备份的取舍

点级撤销**不支持重做**（重做需要反向记录点级差异，收益不值）。
