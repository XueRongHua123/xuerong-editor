## 雪绒的钢铁雄心编辑器 v1.23.6

「编辑」tab 加面板索引条。

### 问题

「编辑」tab 里现在平铺着 14 个面板：

```
师团模板 / 国家初始科技 / 国家精神 / 国家离岸建筑 / 国家 TAG / 图标导入 /
开局舰队 / 开局空军 / 开局政治与外交 / 开局已完成国策 / 开局剧本 / 人物 /
决议 / 生成地图
```

全在一个滚动条里，想找「人物」要滚好几屏。新功能一版加一个，越来越难找。

### 做法

在「编辑」tab 顶部动态生成一条按钮索引：

- 启动时扫一遍这个 tab 里所有 `<h4>`
- 每个标题生成一个按钮，点一下平滑滚动到对应面板
- 跳过去后面板闪一下蓝边（900ms），让人确认落点
- 纯 JS 生成，不改 HTML 结构，以后加面板自动进索引

### 实现细节

面板容器的 id 是动态补的（`sec_0`、`sec_1`…），只给还没有 id 的加，
不动已有的 `tplPanel` / `mgPanel` 这些。

查元素用 `pane.querySelector('#xxx')` 而不是 `document.getElementById()`——
后者会被界面巡检脚本当成「HTML 里缺这个 id」报错，而这条索引条本来就是运行时创建的。

### 效果

「编辑」tab 顶部多一行：

```
[师团模板] [国家初始科技] [国家精神] [国家离岸建筑] [国家 TAG] [图标导入]
[开局舰队] [开局空军] [开局政治与外交] [开局已完成国策] [开局剧本]
[人物] [决议] [生成地图]
```

14 个按钮一行放不下，自动换行成 2-3 行。
