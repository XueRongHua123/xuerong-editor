## 雪绒的钢铁雄心编辑器 v1.18.2

政治图两个显示问题的修复。

### 1. 海洋被画成深色

政治图层里，没有归属国的省统一填了同一个深灰绿 `(46,50,46)`。

问题是大片海洋也走这条路——地图上大西洋、太平洋全变成深色，看起来像地图缺了一块。

muvluvCN+雪绒拓展实测：13264 个省里 9960 个有归属国（75.1%），剩下 3310 个里
既有海洋也有无主陆地（MUVLUV 世界线的 BETA 占领区）。两者被画成同一个颜色。

现在按 `definition.csv` 第 5 列区分：

```
有归属国      → 国家色
海洋/湖泊     → 海色 (26,42,74)
无主陆地      → 中性灰 (46,50,46)
```

实测采样：大西洋 `[26,42,74]`、无主陆地 `[46,50,46]`，区分开了。

### 2. 点海洋省份把侧栏撑满

点一个没有归属国的省，右侧只输出一句：

```html
<div class="mp-k">这块地没有归属国</div>
```

没有外层容器，无内边距，文字直接贴着侧栏边缘铺满整个宽度。

现在包成卡片并区分两种情况：

```
这是海洋，没有归属国          这块地没有归属州
省 4　点陆地省份查看国家        省 1234　点陆地上的省份查看详情
```

卡片有边框、内边距、`max-width:100%`，实测宽 212px 而侧栏 237px，不会撑满。

### 顺带查清的一件事

雪绒拓展（3829617696）是纯 submod：没有 map、没有 `common/countries`、
没有 `history/states`，也没有 `replace_path`。

它靠 `dependencies = { muvluvCN }` 继承地图与国家数据，编辑器能正确解析出三层叠加：

```
原版 → muvluvCN (2800380626) → 雪绒拓展 (3829617696)
国家 116、州 818、有 owner 的省 75.1%
```

图上那些灰色区域是无主陆地，不是数据缺失。
