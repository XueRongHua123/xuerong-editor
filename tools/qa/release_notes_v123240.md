## 雪绒的钢铁雄心编辑器 v1.23.24

补上界面缺的国家参数。

### 问题

后端这几个接口陆续都加了国家参数（`tag` / `country`），但前端表单没跟着改。
界面上点「加部队」「保存模板」「加船」，调的还是老参数，于是全部写进通用文件：

```
history/units/zz_units.txt        没人认领的模板
history/units/zz_units.txt        没人认领的部队
history/units/ARG_1936_naval_legacy.txt   船加到了阿根廷
```

游戏靠文件名的国家前缀判断归属，这些文件它不知道该给谁，所以进游戏什么都看不到。

### 改了什么

| 位置 | 改法 |
|---|---|
| 部队 | 用**该省的归属国**，不需要额外输入框 |
| 模板 | 保存按钮旁加 `TAG` 输入框 |
| 海军 | 加船 / 加特遣队各一个 `TAG` 输入框 |

部队这条值得说一下：部队是在「省」面板里加的，省本身有归属国（`st.owner`），
直接拿它当文件归属最自然，不用让用户再填一遍。

海军的舰队序号含义也变了，提示从「舰队序号」改成「该国第几支舰队（从 0 起）」——
原来填 0 指的是全部 270 支舰队里的第 0 支，那是阿根廷的。

### 现在的语义

```
TAG 填 GER
nvFi 填 0   → GER 的第 1 支舰队（全局索引 82）
nvFi 填 1   → GER 的第 2 支舰队（全局索引 83）
```

TAG 留空时行为不变，还是全局序号。
