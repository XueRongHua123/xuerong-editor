## 雪绒的钢铁雄心编辑器 v1.6.1

修预览的四个问题，其中两个是同一个根因。

### 1. 按钮文字

「打开事件树编辑」→「事件树编辑」。

### 2. 拖动后显示不全 / 适应后整棵树消失

**根因**：`viewBox` 和滚动条同时在管视野。

SVG 的 `width` 是内容像素宽（比如 5012px），容器 `overflow:auto` 于是出现横竖滚动条；
同时我又在改 `viewBox` 做平移缩放 —— 两套坐标系打架，拖一下就跑偏，
点「适应」时 `viewBox` 被设成内容比例（5012×320），而容器是 1400×740，
`preserveAspectRatio` 按较小的一边重新缩放，内容瞬间缩成看不见。

**改法**：

- 容器 `overflow:hidden`，SVG `width/height:100%` 填满容器
- 内容尺寸存到 `data-w` / `data-h`，不再当元素尺寸用
- 视野**只**由 `viewBox` 控制
- `viewBox` 的宽高比**锁死**成容器比例（`containerAR()`），拖动只改 x/y、缩放宽高一起变

实测：拖动前后 `viewBox` 的 w/h 完全不变（`1832.9 × 925.6`），只有 x/y 移动。
「适应」后 56 个节点全部可见（之前是 0）。

### 3. 缩放改为鼠标中心

滚轮时以鼠标所在点为锚点：

```
缩放前鼠标下的内容点 (97.8, 213.6)
缩放后同一点            (97.8, 213.5)
偏移 0.1 像素
```

之前锚点算的是 `body` 的框，而 SVG 元素尺寸和 body 不一致，所以锚点偏掉。
现在统一用 `svg.getBoundingClientRect()`。

### 4. 宽高比 15:1 的细条 → 分层换行

`mvlv_generic` 原来 12 层各排一行，整棵树 5012×320（比例 15.7:1），
塞进 1.9:1 的容器里怎么看都是一条线。

改成**同层超过 7 个节点就换行**，层与层之间加 0.7 行高的空隙：

```
布局尺寸：5012×320 → 1112×890（比例 1.25:1）
```

现在全览是一张规整的分层网格，连线也读得清了。

### 顺带

切树后自动「适应」一次，不用每次手动点。
