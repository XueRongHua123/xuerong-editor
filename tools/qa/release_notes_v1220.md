## 雪绒的钢铁雄心编辑器 v1.2.2

地形层叠上**游戏自己的地表贴图**（`map/terrain/atlas0.dds`）。

### 数据链路

```
common/terrain/00_terrain.txt
  terrain_1 = { type = forest  color = { 1 } texture = 4 }
              ↓                    ↓          ↓
       terrain.bmp 的像素值    地形类别     atlas0.dds 第 4 格
```

`atlas0.dds` 是 **8×8 = 64 格、每格 256×256** 的贴图集，DXT5 压缩。
Pillow 能直接读（41ms，不用额外库）。

### 只调亮度，不混颜色

第一版直接把贴图按 alpha 混合上去，结果整片地形发灰——因为贴图本身是灰色调细节层，
混合会把地形色洗掉。

改成只用**亮度**调制：

```
luma = 0.30R + 0.59G + 0.11B     （贴图颜色 → 亮度）
f    = 0.74 + (luma/255) × 0.56   （0.74 ~ 1.30）
最终 = 地形色 × f × alpha权重
```

色相不变，表面出现花纹。

### 海洋跳过

`atlas0.dds` 里没有水面贴图（`ocean` 的索引借用 `desert` 的 texture 9），
叠上去会把海面弄成水泥地。

水面贴图在另一个文件（`map/terrain/colormap_water_*.dds`），这版不碰，海洋保持纯色 + 弱阴影。

### 纹理起点按省哈希偏移

```
ax = (x + pid*37) % 256
ay = (y + pid*71) % 256
```

相邻省的花纹不对齐，避免一眼看出 256px 的重复网格。

### 性能

| 项 | v1.2.1 | v1.2.2 |
|---|---|---|
| 构建总时长 | 40.5 秒 | 39.3 秒 |
| terrain.png | 4.86 MB | 6.11 MB |

没有变慢：纹理采样有 30 万条缓存，且大部分像素落在同一个贴图格子里。

### 效果

100% 缩放下纹理较细，放大到 200% 以上能明显看出草地、岩石的颗粒感。

### 说明

纹理只在 `terrain.bmp` 与 `provinces.bmp` 同源时生效（v1.2.1 的判断）。
不同源的 mod（如 muvluvCN）走省级地形色，没有纹理——因为连像素级地形都不可信，
叠纹理只会放大错误。
