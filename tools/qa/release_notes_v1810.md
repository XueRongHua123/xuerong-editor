## 雪绒的钢铁雄心编辑器 v1.8.1

三件事：缩放上限、事件树并入事件栏目、事件文本可直接改。

### 1. 只能放大到 400% —— 是写死的上限

`applyZoomFactor` 里：

```js
const k1 = Math.min(4, Math.max(0.08, k0 * factor));   // 上限 4 倍
```

两处都改了（地图滚轮 + 键盘缩放）：

```js
Math.min(32, Math.max(0.06, ...))    // 上限 32 倍
```

现在能放到 3200%，看单个像素都行。

### 2. 事件树并入「事件」栏目

左侧面板本来是「事件」和「事件树」两块，现在合成一块：

```
事件
  [事件树编辑]  [事件编辑器]     ← 两个入口并列
```

### 3. 事件能直接改中文文本

事件树右侧编辑栏多了两个字段：

```
title 键   [mvlv_generic.0.t]
标题文本   [＜简史＞（1944～1999）]      ← 可改
desc 键    [mvlv_generic.0.d]
描述文本   [1944年：日本有条件投降…]      ← 多行
```

点「保存到文件」时：

- 键名变了 → 改事件文件里的 `title = ` / `desc = ` 行
- 文本变了 → 写进 `localisation/simp_chinese/zz_xuerong_evtext_l_simp_chinese.yml`

```yaml
l_simp_chinese:
 mvlv_generic.0.d:0 "测试描述"
 mvlv_generic.0.t:0 "测试标题"
```

只改文本、键名不动的情况也会写（之前会误判成"没有实际改动"）。

### 关于「放大后还是很糊」

v1.7.1 已经把高倍插值改成硬边像素了。截图显示 400%（被上限卡住），
而且看起来仍有插值感——大概率是跑的 v1.7.0 或更早的 exe。

装上这个版本，点「适应」再看：400% 以上应该是清晰的像素格，不是模糊光带。
如果还糊，告诉我，我再看是不是还有别的地方覆盖了 `image-rendering`。
