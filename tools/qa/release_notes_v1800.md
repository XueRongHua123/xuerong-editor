## 雪绒的钢铁雄心编辑器 v1.8.0

细化现在能看形状了，而且把切分算法抽成了一套通用逻辑。

### 1. 形状直接画在地图上

点「预览」后，4 块用不同颜色铺在省界内，边界一目了然——不用先写盘再撤销。

```
省 13063 切成 4 块，面积 3911 / 3870 / 3537 / 2824（共 14148 像素）· 形状已画到地图上
```

改块数、切省、应用后都会自动清掉预览。

### 2. 切分算法抽成通用件

原来是 `_refine_seeds` + `_refine_split` 两个函数写死"像素"这个概念。
现在抽出一个通用的：

```python
_refine_grow_units(units, neighbors, k, coord)
    单元      = 任意可编号的东西（像素 / 省 / 州）
    neighbors = 邻接关系
    coord     = 坐标（用来选种子）
```

省细化就是"单元 = 像素，邻居 = 4 邻域"。

**顺带修正了面积均衡**：之前按"层数"同步生长，实际按行推进，导致细长区域被一个种子吃光。
现在按**单元数**精确分配预算：

| | 之前 | 现在 |
|---|---|---|
| 4 块面积 | 5121 / 4934 / 2159 / 1928（差 2.6 倍） | 3911 / 3870 / 3537 / 2824（差 1.4 倍） |
