# 雪绒的钢铁雄心编辑器 v1.25.3

## 本次改了什么

> **小更新**｜国家精神编辑器重做为三页签分栏布局，修复新建条件块写偏外层与旧版占端口/浏览器缓存问题

这一版彻底整理了国家精神编辑器的界面结构，让常见名称、图标与修正项调整在一屏内就能完成，同时修掉新版覆盖旧进程端口、静态资源缓存以及首次写入 `allowed`/`trigger` 块位置错误的问题。

## 一、国家精神编辑器可用性改版

- **三页签分栏不再一列挤满**：右侧编辑区拆为「属性与修正项」「条件 allowed / trigger」「脚本原文」三个页签。常用编辑全留在第一页签，1280×720 小屏也无需滚动即可同时看到名称、图标、修正项、快捷按钮以及顶部和底部的保存按钮。
- **常用修正项一键点选与删除**：第一页签内置常用 `modifier` 快捷标签（每日政治点、稳定度、战争支持度、工厂产出、科研速度、消费品），点击即可生成带中文名称说明的修正项卡片，并支持点右上角 `×` 直接移除不再需要的修正项。
- **「全部 / 仅当前 mod」列表过滤**：国家精神列表上方新增范围切换按钮，做 Submod 时点「仅当前 mod」即可屏蔽数百条原版条目，避免因同名 key 或原版内容干扰检索。
- **收起少用的多语输入**：国家精神、装备、科技、事件四个编辑弹窗中，日语与英语字段统一收进可展开折叠块，日常只改中文时不再白白占用一整屏高度。

## 二、写盘与版本更新稳定性修复

- **修复新增 `allowed` / `trigger` 写到括号外层的 bug**：`set_raw_block()` 现已区分内层体与完整外层定义块，在没有旧 `allowed`/`trigger` 块的国家精神/装备/科技/事件里首次填写条件时，会准确插入末尾 `}` 内部，不再写出破坏外层 `country = { ... }` 结构的错位块；同时也修正了替换已有块时少截一位换行的问题。
- **「脚本原文」页签直改不被旧表单反盖**：停留在「脚本原文」页签手动修改脚本后直接点击保存，不再被第一页签的旧字段覆盖。
- **防止旧版进程与浏览器缓存拦截新界面**：Windows 本地 HTTP 服务改用独占端口绑定（`SO_EXCLUSIVEADDRUSE`），遇到旧窗口占用 8766 时自动顺延空闲端口并打印提示；首页与 `/web/` 静态脚本样式统一附带 `Cache-Control: no-store` 禁止强缓存，升级新版后打开网页即见最新界面。

## 升级说明

下载新版压缩包解压覆盖即可。如果电脑上还开着旧版编辑器窗口，建议先关闭旧窗口再打开新版（即便忘关，新版也会自动切换到相邻空闲端口打开，不再连到旧窗口）。
