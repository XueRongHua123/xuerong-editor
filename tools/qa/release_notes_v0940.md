## 雪绒的钢铁雄心编辑器 v0.94.0

地图编辑的地基：**原位写 BMP + 区块撤销**。这是涂色改省界的前置，本版只做引擎，界面下一版接。

### 为什么不用 Pillow 重存

`provinces.bmp` 有 33 MB。用 Pillow 打开再 save 会重写整个文件结构，一旦哪一步出错就是整幅地图损坏。
现在改成**原位写**：读到 BMP 头里的像素数据偏移（54）、行宽（16896）、行序（自下而上），
直接 seek 到目标像素写 3 个字节（BGR 顺序），文件的其余部分一个字节都不动。

### 撤销用区块，不用整幅

每次提交只记录**受影响矩形**的原始像素（87 个像素 → 15×8 的区块，1.8 KB），
而不是备份 33 MB。撤销就是把这块写回去。

### 接口（`/api/map_paint`）

| act | 作用 |
|---|---|
| `begin` | 开始一次编辑事务 |
| `dab` | 在事务里画一笔（圆，给定半径与 RGB） |
| `commit` | 提交：先存区块原始像素，再原位写入 |
| `undo` / `redo` | 撤销 / 重做 |
| （空） | 查询当前栈深度 |

### 实测（在 33 MB 副本上，不碰真实 mod）

```
BMP: w=5632 h=2048 bpp=24 offset=54 row=16896 top_down=False
待写像素: 87
提交: pixels=87, rect=[117,117,15,8]
(120,120) 现在: (255,0,255)  ← 目标点已改
(300,300) 未动: (97,37,232)  ← 远处未受影响
撤销 → md5 与原文件完全一致: True
重做 → 目标点又变回 (255,0,255): True
二次撤销 → 再次恢复: True
```

### 边界

- 只支持 24 位 BMP（HOI4 的 provinces.bmp 都是）
- 写入落在**叠加链顶**（子 mod），父 mod 与原版不写
- 本版没有界面，下一版接画笔：选目标省 → 拖动涂抹 → 提交/撤销
