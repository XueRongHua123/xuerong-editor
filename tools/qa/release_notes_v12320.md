## 雪绒的钢铁雄心编辑器 v1.23.2

`rivers.bmp` 与 `cities.bmp` 的格式修正。

### 之前是什么状态

这两张图一直是 `write_blank_indexed` 写的全 0 图，调色板也是随便造的。
HOI4 读这两张图用的是**固定调色板索引**，全 0 意味着整张图都是一种地形，不对。

### 河流识别没调通，说清楚

想从真实地图里自动找出河流（蓝色细线），试了两个方案都不行：

**方案 A：按连通块面积分**
河流和海在河口连成一块，面积合并后超过阈值，全被判成海。

**方案 B：形态学开运算**
腐蚀 3 次再膨胀 3 次，细线确实消失了，但膨胀会把海边缘扩出去，
紧贴海的河段被吞掉。

**方案 C：距离变换**
理论上对（河宽 2 → 距离 1；海很宽 → 距离 24），但实测 `thin_water`
只返回 2 个像素，没到预期。这个还没查清。

**所以**：这一版 `rivers.bmp` 的格式对了，但**图里没有河**——
所有像素都是 254（陆）或 255（海）。从 GeoJSON 的 LineString 生成河流
会是更可靠的路径，留到下一版。
