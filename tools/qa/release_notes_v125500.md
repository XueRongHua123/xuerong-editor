## 雪绒的钢铁雄心编辑器 v1.25.5

全量国家精神/事件/科技/装备删除及主栏名称保存改为增量秒级更新不再阻塞读条，修复事件删块截断 `countr` 与前缀误伤，并依据完整原版实机 UI 全流程走查补全国家精神 `GFX_idea_*` 图标选择、浮窗避让、事件选项聚焦与向导默认 `TAG`。

### 主要改进

1. **国家精神 / 事件 / 科技 / 装备全量增量删除 + 主栏本地化秒存**
   - 删除国家精神、事件、科技或装备不再触发全量 `_reload()` 与全屏遮罩读条，后端原地移出条目并按叠加链恢复被同 ID 异文件名覆写遮蔽的下层条目，前端局部刷新列表，完整原版环境实测删除耗时降至 `0.10s–0.20s`。
   - 修复主栏国策「保存名称/描述」保存后触发全量重载的问题，改为原地保存并秒级回显（完整原版环境实测 `0.12s`）。
   - 修复 `delete_event()` 用 `_event` 回退切块时在部分缩进场景残留截断 `countr`、以及未加 ID 边界断言误匹配同前缀事件的缺陷。

2. **真实原版 HOI4 全流程走查与界面交互打磨**
   - **国家精神图标选择器支持 `GFX_idea_*`**：`/api/icons?kind=idea` 返回精神专属图标并过滤 `_shine` 重复项；图标窗分批懒加载避免千图并发卡顿、加载后保留已填搜索词、选定后自动剥离 `GFX_idea_` 前缀填入 `picture`。
   - **浮窗与引导卡避让大弹窗与侧栏**：引导卡 `#guideBox` 与看板娘浮窗停靠于主画布边角且层级（`z-index: 44/45`）低于编辑弹窗（`60`），不再遮挡左侧装备/科技折叠栏与弹窗操作按钮。
   - **向导与表单细节修复**：新建模组向导留空国家 `TAG` 时默认回退 `GER` 并补上创建/加载反馈；事件「添加选项」后自动聚焦新生成的选项文本输入框；切换条目触发异步 `/api/raw` 时若用户已开始输入则保留用户编辑内容不被迟到响应覆盖；打包发布弹窗预检及导出期间锁定按钮并展示进度。

3. **回归验证与跨模组兼容**
   - `tests/test_submod_e2e.py` 新增 `test_16_incremental_delete_and_ux_dogfood_fixes`，覆盖增量删除与同层遮蔽恢复、事件前缀边界、`/api/icons?kind=idea`、引导浮窗层级与向导空 TAG 兜底。
   - 发布前已完成 `compileall`、`node --check`、导入边界与通用性审计、HTTP 契约测试、224 路由全量冒烟、`browser_smoke`、`regress_all` 与 16 项端到端回归测试。
