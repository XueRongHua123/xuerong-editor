## 雪绒的钢铁雄心编辑器 v1.2.1

修两个把地形图压暗/弄错的问题，两个都是**所有 mod 都受影响**的真 bug。

### 1. `edges.png` 没有透明通道，压暗了整幅地形

省界图原来是 RGB：**白线画在纯黑背景上**。

前端按 70% 不透明度叠上去时，黑色背景也一起盖上来：

```
最终色 = 地形色 × 0.3 + 黑 × 0.7 = 地形色 × 0.3
```

亮橙的撒哈拉 `(202,135,0)` 显示成 `(61,41,0)` 的暗棕——这就是之前地形"脏、发暗"的真正原因。

现在 `edges.png` 存成 **RGBA**：白线不透明、其余全透明。省界滑块默认 80%（只是线的强度，不再影响底色）。

### 2. `terrain.bmp` 与 `provinces.bmp` 不同源时地形分布完全错乱

muvluvCN 换了 `provinces.bmp` 和 `definition.csv`，但**没有换 `terrain.bmp`**：
它用的还是原版那张 5632×2048 的地形索引图，和它自己的省界毫无关系。

所以大片橙色（plains）、灰蓝（mountain）随意铺在不相干的地方——截图里看到的就是这个。

京都燃烧没这个问题，因为它三张图都是自己的（`provinces.bmp` / `terrain.bmp` / `heightmap.bmp` 全来自 mod）。

**现在会自动判断**：

```
terrain.bmp 与 provinces.bmp 是否来自同一层？
  是 → 像素级地形（保留省内植被变化）
  否 → 改用 definition.csv 的省级 terrain 着色（永远可信）+ 高度阴影
```

### 3. 顺手修的

- **地形色亮度归一化**：`marsh` 是 `(76,96,35)`、`plains` 是 `(255,129,66)`，差 3 倍，
  直接铺开一半发黑。现在把陆地的最大分量抬到 210 左右（色相不变），海洋/湖泊保持原值。
- **旧的双重明暗去掉**：`terrbuf` 里还留着旧的「terrain.bmp 灰度 × 0.72~1.18」，
  又叠一次真实高度阴影 → 压暗一倍。现在只用高度阴影。
- **光照改乘法模型**：`composite(bright, black, shade)` 会把背光面压到接近黑，
  改成「提亮 1.35 倍 × 系数 0.72~1.27」，暗部仍有约 0.97 倍。

### 效果对比

muvluvCN（terrain.bmp 来自原版）修复后：地中海、北非、意大利的橙/蓝都回来了。

### 教训

「看起来暗」不一定是配色问题。这次两个 bug 都是**叠加层的行为**（无 alpha 的黑色背景、双重明暗），
只看 terrain.png 文件本身是正常的，光看图片再怎么调参都没用。
