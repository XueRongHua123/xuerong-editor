## 雪绒的钢铁雄心编辑器 v1.0.6

观感改进第一批：**配色、边界、地形纹理、缩放渲染**。

### 1. 地形层改成游戏自己的配色

之前是按地形名（plains / forest / ocean）填**随机柔和色**，所以看起来是色块拼贴。

现在读游戏数据：

- `common/terrain/*.txt` 里每个类别的 `color = { r g b }`
  （ocean 40,83,176 · forest 89,199,85 · plains 255,129,66 · mountain 157,192,208 · hills 248,255,153）
- 再叠 `map/terrain.bmp` 的灰度做明暗（0.72~1.18 倍），同一种地形也有起伏

结果：海洋是深蓝、森林是绿、平原是橙棕、沙漠是黄褐——和游戏内地形图一致。
MUVLUV 的自定义地形（`hive_mainhall` 黑色巢穴）也能正确取到自己的颜色。

### 2. 边界线不再压过色块

- 边界像素从纯白 `250,250,250` 改成淡灰 `205,209,203`
- 边界层默认不透明度 0.35 → 0.7（恰好可见，不抢戏）

放大后不再是一条糊住半个屏幕的白带。

### 3. 省色块提高饱和度

`_hsv_hex(pid, 0.5, 0.9)` → `_hsv_hex(pid, 0.72, 0.96)`，色块更鲜明；
州色块也从 0.42/0.8 提到 0.62/0.92。

### 4. 缩放时自动切换渲染方式

- `k ≤ 1.4`：`image-rendering: pixelated`（像素锐利，涂色/描边时看清每个像素）
- `k > 1.4`：`image-rendering: auto`（双线性插值，边界不再是楼梯）

实测：`1.6×` 与 `3×` 时 `smooth=true`，点「1:1」回到 `k=1` 时自动变回 `smooth=false`。

### 说明：这不是矢量

参考项目放大 8.6 倍时边界也是锯齿（位图放大必然如此）。他看起来精细，主要靠：
高饱和配色 + 细边界 + 真实地形纹理。这三条这版都对齐了。

真要「拉多远都锐利」，只能把每省轮廓提成矢量路径（13264 个省，几十 MB 数据），成本 2–3 天，暂不做。

### 附带

- 地形层构建时多读一张 `terrain.bmp`（11.5 MB），构建时间从约 33 秒增加到约 36 秒
