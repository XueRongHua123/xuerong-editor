# 雪绒的钢铁雄心编辑器 v1.25.2

## 本次改了什么

> **小更新**｜修通国策名称顶栏保存、本地化弹窗即时同步，以及国家精神/科技/事件弹窗布局与 modifier 快捷保存

这一版专门修掉实际桌面操作时踩出来的五个阻断体验与写盘 bug，让国策改名、本地化调整和新建国家精神都能一路顺畅保存进游戏。

## 一、国策与本地化修改保存

- **顶栏「保存」同步保存国策名称/描述**：在右侧国策属性栏修改中文、英文或日文名称与描述后，现在直接点顶部「💾 保存」或按 `Ctrl+S` 就会一并写入本地化文件，不用再单独点击「保存名称/描述」。同时修掉了日文未初始化与跨窗串联英文精神框的残留问题。
- **本地化弹窗修改立即生效并刷新画布**：在「本地化」面板的「浏览与编辑」修改译文并点击「保存」（或直接在输入框按回车）后，不仅立即写盘并更新状态提示，还会同步刷新画布节点与右侧面板名称；同时锁定遍历顺序确保 `replace/` 子目录永远最终覆盖同语言文件。
- **「加载原版参考」不再反盖已加载 mod**：修掉了先打开/新建 mod 再点击「📖 加载原版参考」时，原版目录被追加到叠加链末尾反盖掉所有 mod 改动并导致报错「没有可写的模组目录」的问题；原版永远位于最底层只读底座。

## 二、国家精神、科技、事件、装备弹窗优化

- **保存按钮不再掉出屏幕外**：为国家精神、装备、科技、事件四个大编辑弹窗的右侧表单加上独立滚动区域，并在弹窗顶部右上角和固定底栏同步常驻主色「💾 保存」按钮，1280×720 小屏也能一眼看见并点击保存。
- **快捷添加修正项（modifier）与防误填提示**：修复新建国家精神时往空 `modifier = {}` 块写入新属性会被静默丢弃的 bug；弹窗内新增「➕ 添加修正项」输入栏与常用 HOI4 属性推荐下拉，不用手写大括号即可直接添加 `political_power_gain`、`stability_factor` 等修正项，且在名称/描述框补上清晰占位提示防止误填入代码。
- **新建/保存加上明显加载反馈**：点击「新建精神 / 新建科技 / 新建事件 / 保存」触发全量刷新时，立即展示加载进度与计时提示，不再干等无响应；操作成功提示条居中悬浮于所有弹窗最上层。
- **修复来源提示错位**：修复切换列表条目时偶发异步乱序及先建 mod 后加载原版导致新建条目误显示「来源: Hearts of Iron IV（只读）」的问题。

## 升级说明

直接下载新版覆盖替换旧程序即可，原有的模组文件与配置无需清理。
