## 雪绒的钢铁雄心编辑器 v1.22.1

地图生成的两处实质改进：**省大小均衡**、**战略区按地理位置聚类**。

### 1. 省大小均衡

上一版 Voronoi 切出来的省大小悬殊，海岸线附近有大量几十像素的碎块——游戏里点不到、AI 不会守。

新增 `balance_sizes(labels, min_size)`：

- 统计每个省的像素数
- 小于下限的省，找它上下左右邻居里出现最多的那个省，整块并过去
- 重复几轮直到没有过小的省或达到上限
- 最后重新编号

实测（600×240、80 个省、下限 800 像素）：

```
得到 80 个省
均衡省大小（下限 800 像素）…
  80 → 76 个省
```

### 2. 战略区 / 补给区按地理位置聚类

上一版按省 id 顺序每 60 个切一区，结果地理上完全乱——西伯利亚的省可能和地中海的省在同一个战略区。

新增 `group_provinces_by_location(labels, k)`：

1. 算每个省的**像素质心**（`centroids`）
2. 对质心做 **k-means 聚类**
3. 同组省归一个战略区/补给区

实测：

```
按地理位置聚类…
  2 个地理组（战略区）、1 个（补给区）
```

（这一版只有 2 组是因为默认按省数自动算：76 省 ÷ 60 ≈ 2）

### 新增可调参数

```
POST /api/map_generate
  balance         true/false     是否均衡省大小
  min_province_px 800            省像素下限
  n_regions       null           战略区数（留空自动）
  n_supply        null           补给区数（留空自动）
```

界面也加了对应控件：

```
[✓] 均衡省大小 [800]
[战略区数] [补给区数]
[输出目录_______] [生成]
```

### 实测完整流程

```
生成 600x240、80 个省 → 522ms
  均衡后 76 个省
  2 个战略区、1 个补给区（按质心聚类）
```
