## 雪绒的钢铁雄心编辑器 v0.61.0

AI 面板和雪绒悬浮球一起迭代。

### AI 面板

- **🧪 测试**：用当前配置发一条 ping，面板上直接显示 `✓ 200ms` 或错误原因，不用猜是 Key 错还是网络问题
- **提问模板**：一排快捷 chip —— 写国策效果 / 翻译三语 / 检查脚本 / 解释报错 / 写一个事件，点一下填进提问框再改
- **最近提问**：保留最近 12 条（内存），点一下回填问题与上次的回答；面板重开不丢；🧹 清空
- **耗时与状态**：每次发送后在结果上方显示 `✓ 1420ms`，失败时提示"可点测试看连通性"
- 双击「API Key」标签可以临时显示/隐藏密码

### 雪绒悬浮球

- **右键菜单**：AI 助手 / 命令面板 / 项目体检 / 国家中心 / 州·地块 / 隐藏雪绒
- **双击**：直接打开命令面板（单击仍是 AI 面板）
- **加载状态联动**：添加 mod、加载原版、卸载时球体会有一圈向外扩散的光环，加载结束自动停
