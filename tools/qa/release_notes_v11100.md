## 雪绒的钢铁雄心编辑器 v1.11.0

铁路这一块做完整了：读取、可视化、改等级、增删省、补给区。

### 1. 读取

`map/railways.txt` 两种写法都认：

```
行式  <等级> <省数> p1 p2 p3 ...
块式  railway = { level = N provinces = { p1 p2 ... } }
```

### 2. 可视化

图层预设新增「铁路」：

- 黄色折线，线宽按等级（1 级细、5 级粗）
- **红色 = 断连**（相邻两省不接壤）
- 线宽随缩放自适应，18% 下压细不会糊成一片

### 3. 编辑（右侧新增「铁路」页）

点列表里的任意一条 → 下方出现编辑区：

```
等级        [5]
省份序列    [6521 11444 3312 6282]
[保存]  [删除这条]
```

**保存时做邻接校验**：相邻两省必须接壤，否则直接拒绝并列出不接壤的那几对。避免手滑写出断连铁路。

实测：把第 0 条的等级从 3 改成 5，文件里 `3 4 6521 11444 3312 6282` 变成 `5 4 6521 11444 3312 6282`，带 BOM 保留。

### 4. 补给区

同页下方列出全部补给区：

```
区 1　价值 12　4 州　5,85,763,807
```

muvluvCN 只有 1 个补给区（原版也只有 1 个）。

### 性能

| 操作 | 之前 | 现在 |
|---|---|---|
| 断连检查（1661 条铁路） | 逐段调邻接 → 估 5 小时 | **3.7 秒** |

`_all_prov_neighbors` 一次扫描建全图邻接表，按 bmp 的 mtime 缓存。

### 两个渲染/交互坑

**铁路与矢量边界共用 canvas**：分开画时边界那一步的 `clearRect` 会把铁路擦掉。改成同一次绘制。

**低缩放省界**：13264 个省在 18% 下每省只有几像素，边界挤成整片白网。现在 `k < 0.42` 跳过省界，铁路照画。
