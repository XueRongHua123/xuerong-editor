## 雪绒的钢铁雄心编辑器 v1.17.0

州视图能改了：直接改归属国、批量增减省。

### 之前

v1.9.3 做了「州视图点选州」，但只能看：

```
州 809　省数 6　归属国 SOV
```

要改归属国得切到州面板，要挪省得逐个点「移入目标州」。

### 现在

州视图点选州，右侧直接出现编辑区：

```
州 1
  省数      3
  归属国    FRA
  类别      town

改归属国
  [GER]  [保存]
  已写入 history\states-Corsica.txt

批量增减省
  （用地图框选省后操作）
  [并入此州]  [移出此州]
  并入 2 个省
```

### 改归属国

输入 TAG（大小写不敏感，自动转大写），点保存直接写 `history/states/*.txt` 的 `owner` 字段。

实测州 1（Corsica）从 FRA 改成 GER，文件写入成功。

后端做校验：TAG 必须是已加载的国家，否则拒绝。

### 批量增减省

- **并入此州**：把地图上框选的省全部加进当前州
- **移出此州**：把这些省从当前州摘掉

用的是现有的 `/api/state_province` 接口，前端逐个调，最后汇总「并入 N 个省，失败 M 个」。

实测框选 2 个省并入州 1，成功。

### 一个数据坑

muvluvCN 里有「幽灵州」——`STATES` 里登记了 id 和文件名，但文件实际不存在。

比如州 822 记录的文件是 `822 - Chukotka.txt`，磁盘上没有。

在这种情况下改 owner 会返回：

```
州文件不存在：history\states\822 - Chukotka.txt
```

这是 mod 本身的数据问题，不是编辑器的问题。选到真实存在的州（如州 1）就正常。

### 说明

批量增减省走的是逐个请求，选几百个省时会比较慢（每个请求约 100ms）。
如果实际使用中觉得慢，可以加一个后端批量接口。
