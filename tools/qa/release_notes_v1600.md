## 雪绒的钢铁雄心编辑器 v1.6.0

国策预览有了缩放拖动，事件树从「预览」升级成「编辑」，能新建和删除命名空间。

### 1. 两个预览都能滚轮缩放 + 左键拖动

操作 `viewBox` 而不是 CSS transform：

- **滚轮**：以鼠标位置为锚点缩放（不是以中心），滚哪缩放哪
- **左键拖动背景**：平移画面（拖节点不触发，留给节点自己的点击）
- 「适应」按钮一键回到全览

实测：`viewBox` 从 `0 0 2328 1272` 缩放后变 `124.7 68.2 2078.6 1135.7`，拖动后变 `302.9 196.8 …`。

### 2. 事件树「预览」改名「编辑」，挪出成独立一栏

左侧面板原来挂在「国策树」下面，现在是独立的一块：

```
国策树
  [图形预览]
  （树列表）

事件树
  [打开事件树编辑]
```

### 3. 双击节点直接编辑事件

在事件树里双击一个节点 → 关闭预览 → 打开事件编辑器并选中那个事件。

单机点击还是看信息（id、标题、文件、深度）。

### 4. 全新事件树 / 删除事件树

预览头部多了「新建」「删除」：

**新建**：输入命名空间名（字母开头）→ 生成 `events/zz_xuerong_<ns>.txt`，内容是能直接跑的样板：

```hoi4
add_namespace = my_events

country_event = {
	id = my_events.1
	title = my_events.1.t
	desc = my_events.1.d
	is_triggered_only = yes

	option = {
		name = my_events.1.a
	}
}
```

创建后提示要补哪三个本地化键。

**删除**：删掉该命名空间的所有事件块 + `add_namespace` 声明；文件删空了就把文件本身移除。改前有 snapshot 备份。

实测闭环：`创建 demo2 → 删除 demo2 → removed:1, 文件已删空移除`。

### 5. 改善「第一层太长」

原来一个命名空间的事件全画出来，第一层十几个节点排成一长排，得横向滚。

现在选中任意节点 →「只看下游」→ 只保留从它出发能触发到的子图。

实测 `mvlv_generic`：56 个节点 → 选中间一个事件 → 只看下游变成 **10 个**；点「显示全部」恢复 56 个。

### 踩的坑

`makePannable` 这个辅助函数一开始被插进了 `<style>` 里（锚点用的是 CSS 注释），浏览器报 `makePannable is not defined`。挪到 `<script>` 区才正常。

### 还没做

- 事件节点的「快捷编辑」只到「打开编辑器」，不能在图上直接改 title/option
- 新建的命名空间不会自动生成本地化文件（只提示要补哪些键）
