## 雪绒的钢铁雄心编辑器 v1.23.0

地图生成加到**六种来源**，开放给玩家自己选。

### 六种来源一览

| 来源 | 玩家给什么 | 省界来源 | 效果 |
|---|---|---|---|
| **geojson** | `.geojson` 矢量行政区划 | 真实省界 | **最准**，省名也是真名 |
| **terrain_map** | 一张真实地图/卫星图 PNG | 自动识别海陆 + Voronoi 切 | 海岸线真，省界假 |
| **lineart** | 黑白线稿 PNG | 线条围出来的区域 | 自己画的世界 |
| **image** | 任意图片 | 按颜色区块 | 已有色块图 |
| **mask** | 海陆掩码 PNG | Voronoi 切 | 有轮廓没省界 |
| **procedural** | 什么都不用给 | 分形噪声 + Voronoi | 架空世界 |

### 新增：GeoJSON 来源

```
POST /api/map_generate  {source: "geojson", src_path: "x.geojson", width, height, bbox}
```

**处理流程**：

1. `json` 读 features，取 `properties.name` 当省名
2. 扫全部坐标算 bbox（也可用参数 `bbox` 指定区域）
3. 等距圆柱投影：`lon → x`、`lat → y`
4. `PIL.ImageDraw.polygon` 逐多边形填唯一 RGB
5. **洞处理**：先填所有外环，再用黑色把内环挖掉
6. 按 RGB 反查 label，丢掉太小的块，重新编号
7. `definition.csv` 直接用真实省名

**MultiPolygon** 也支持（每个子多边形单独填）。

### 新增：真实地图来源

```
POST /api/map_generate  {source: "terrain_map", src_path: "map.png", n_provinces}
```

**处理流程**：

1. 按 RGB 判海：蓝通道明显高于红绿 + 饱和度 > 0.12
2. 深蓝单独判（`b > r*1.5`）
3. 做两轮邻居投票去噪（陆地里零星水点、水里零星陆点）
4. 陆地上 Voronoi 切省
5. **顺便反推地形**：绿→平原、褐→丘陵、暗褐→山地、白→雪、砂黄→沙漠

地形提示目前存在返回值里（`terrain` 数组），还没写进 `terrain.bmp`——下一版接。

### 实测

**GeoJSON**（3 个矩形多边形）：

```
已生成 3 个省的地图（300x200）
definition.csv:
  0;0;0;0;sea;ocean;0;
  1;61;152;140;land;plains;0;北部省
  2;34;95;235;land;plains;0;南部省
  3;155;122;161;land;plains;0;东部省
```

省名是真的。

**真实地图**（上半蓝海、下半绿陆、中间褐山、底部白雪）：

```

得到 20 个省，陆地 30000 像素
均衡省大小（下限 800 像素）… 20 → 20 个省
```
