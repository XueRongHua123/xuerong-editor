# 雪绒的钢铁雄心编辑器 v1.25.4

## 本次改了什么

> **小更新**｜国家精神/事件/科技/装备新建与保存改增量秒存（告别全量重载读条），修复事件编辑器右侧标题/描述/选项不回填的 bug

这一版解决了编辑国家精神、事件、科技和装备时最影响手感的等待与回填问题：新建和保存不再重新解析整套原版模组并弹窗读条，改完即刻落盘刷新；事件编辑器右侧同步完整展示已保存的中文标题、正文描述和选项文本。

## 一、保存与新建不再等待全量读条

- **单条目增量更新内存（取消 `_reload()` + `loadData()`）**：新建或保存国家精神、事件、科技、装备时，后端写入文件并就地更新内存中对应条目，随响应返回最新项视图；前端直接刷新左侧列表与当前选中条目，不再触发全库重载、全屏进度遮罩与整棵国策画布重建。
- **仅删除留全量兜底**：删掉 submod 覆写条目时仍保留全量重载，保证底层原版或父层条目能正确露回。

## 二、事件及三类弹窗本地化回填与优先序修复

- **事件编辑器右侧完整显示标题、描述与选项**：`/api/raw` 现随脚本原文一并返回 `loc`（包含标题、描述、各选项 `option.name` 文本以及日/英语修改稿）。打开、搜索选中或保存事件后，右侧中文标题、描述与每一行选项输入框都会即时填回已保存内容，左侧列表同时高亮当前选中项；选项输入框也兼容浅色纸页主题。
- **科技与装备同步回填描述**：选中科技或装备时，同样读取并回填已有描述与可选多语内容。
- **多语保存不再反盖中文**：`save_loc()` 调整写入内存表的更新顺序，确保同时填写英文/日文与中文时，列表和面板优先显示简体中文。
