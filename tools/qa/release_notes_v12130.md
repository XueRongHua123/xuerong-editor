## 雪绒的钢铁雄心编辑器 v1.21.3

师团模板编辑界面 + 编制格可视化。

### 兵种解析

新增 `load_battalions`：解析 `common/units/*.txt` 里的 `sub_units` 块。

实测 muvluvCN：**74 个兵种，6 组**（armor 5 / infantry 18 / support 12 / tsf 6 / xg 1 / other 32）。

每个兵种带 `group`、`type`、`sprite`、`map_icon_category`。

```
POST /api/battalions
```

### 模板编辑界面

侧栏「师团模板」区：

```
[载入模板]
331                     2/0
331b                    3/1
…
```

点一行打开编辑器：

```
[331_____________]

编制格（点格选兵种）
┌──┬──┬──┬──┬──┐
│ma│ma│+ │+ │+ │
├──┼──┼──┼──┼──┤
│+ │+ │+ │+ │+ │
└──┴──┴──┴──┴──┘

支援格
┌──┬──┬──┬──┬──┐
│+ │+ │+ │+ │+ │
└──┴──┴──┴──┴──┘

[保存] [删除] [新建]
```

- 编制格 5×5，支援格 5×1
- 点格子弹输入框填兵种 id（留空删除）
- 有兵种的格子高亮
- 保存调 `/api/template_save`
