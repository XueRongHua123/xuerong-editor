## 雪绒的钢铁雄心编辑器 v0.89.0

修的是**编辑器自身**的问题，不是 mod 的。

### 1. 样式表里 29 条死规则（已删除）

界面样式经过十几次改版累积，同一选择器被定义两三遍，后面的把前面的整个吃掉。
查出来 **57 处重复选择器**，其中 **29 条是完全被后续规则覆盖的死规则**，已删除（-1597 字符）。

死规则最坏的地方不是占体积，是**改了不生效**：上一版我改图层面板背景色时，
改的就是一条后来被覆盖的规则，看起来"改了没变化"，实际上改错了对象。

删完跑巡检：27 个界面状态 × 双主题 × 两档视口，0 违规；功能探针 0 报错。

### 2. 两套主题变量（已合并）

`:root` 和 `body.theme-paper` 各被定义两遍，第一套的 `--bg / --panel / --text` 全是死值，
只有 `--node`、`--svg` 还在生效。现在把这两个变量迁进第二套，删掉第一套（-301 字符）。

### 3. 地图缓存键缺两项（已补）

图层缓存只认 `provinces.bmp` 和 `definition.csv` 的修改时间。但 `state.png`、`political.png`、
`region.png` 还依赖州历史和战略区定义——**改了州归属，地图上的州色块不会更新**，看起来像"没改成功"。

现在缓存键加入 `history/states/*.txt` 与 `map/strategicregions/*.txt` 的最大修改时间。

### 4. 缓存过期无提示（已修）

缓存键一改，旧图层全部作废。之前界面只会说"图层未构建"，用户不知道是版本升级导致的还是自己点错了。

现在记录上次构建（`cache/map/_last.json`），同来源下缓存键变化时提示：

> 图层缓存已过期（2026-10-26 12:00:00 的数据或版本有变），点「构建图层」重建

实测两种情形：key 不同 → `stale: true` 且带上次构建时间；key 相同 → `stale: false`。

### 说明

这四条的共性是「看起来正常、实际行为与预期不符」，只能靠扫描和对比发现，不是崩溃类 bug。
