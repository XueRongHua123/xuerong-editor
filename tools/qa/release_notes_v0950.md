## 雪绒的钢铁雄心编辑器 v0.95.0

**涂色改省界**：左侧 🖌 工具已启用，可以在地图上涂抹，把一片像素划给指定省。

### 怎么用

1. 左侧工具栏点 🖌（涂色）
2. 右侧填「目标省号」（涂成哪个省）
3. 调笔刷半径（1–30 px）
4. 在地图上按住左键拖动涂抹，右下角显示「待涂 N 像素」
5. 点「应用（写盘）」真正写入，随后自动重建图层
6. 出错点「撤销上一笔」——区块级恢复，不是普通文本撤销

### 安全边界

| 情况 | 行为 |
|---|---|
| 原版目录 | 拒绝写入 |
| submod（地图来自父 mod） | **拒绝写入**，提示「链顶 mod 没有自己的 provinces.bmp」 |
| 正常 mod | 只写该 mod 的 `provinces.bmp`，其余字节不动 |

写入采用**原位写**：解析 BMP 头的像素偏移（54）、行宽（16896）、行序（自下而上），
直接定位写 3 个字节，不重存 33 MB 整幅文件。

撤销只存受影响矩形的原始像素（87 像素 → 19×7 区块），不是备份整幅。

### 实测（33 MB 副本，不碰真实 mod）

```
01 begin   : ok
02 dab x3  : 87 像素
03 state   : pending=87
04 commit  : pixels=87, rect=[297,297,19,7], undo_depth=1
05 文件变化: True
06 undo    : restored=87
07 完全还原: True   ← md5 与原文件一致
08 redo    : ok
09 再变化  : True
10 终态还原: True
```

### 已知限制

- 只在副本上验证过完整链路，真实 mod 上尚未实操（第一次用建议先备份 map 目录）
- 涂完不自动改 `definition.csv`（省 id 不变，只改哪些像素属于哪个省）
- 涂色后的省连通性要用「地图检查」自己复核
- 笔刷目前是圆形硬边，没有羽化/直线工具
