## 雪绒的钢铁雄心编辑器 v1.9.5

继续还技术债，两项。

### 1. 底图改全分辨率

`base.png` 一直是地图的一半尺寸（2816×1024），大屏放大看底图会糊。

改成全分辨率（5632×2048）后，文件大小几乎没变：

```
半分辨率 2816×1024  →  全分辨率 5632×2048
体积基本一致（1.28 MB）
```

PNG 压缩吃掉了像素翻四倍带来的体积增长——底图颜色少，压缩率高。

构建时间没明显变化（33.4 秒，之前 38 秒）。

### 2. 预览窗口 resize 后视野自动校正

节点图预览（国策树 / 事件树）的 `viewBox` 高宽比锁定在打开那一刻的容器比例。
把浏览器窗口拉大或缩小后，比例不对了，内容会偏或者缩成一条。

现在 resize 后 180ms 防抖重算一次比例（保持当前缩放级别，只校正长宽比）。
