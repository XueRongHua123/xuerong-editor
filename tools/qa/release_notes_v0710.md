## 雪绒的钢铁雄心编辑器 v0.71.0

地图来了：只看不改的省 / 州地图预览，和州面板联动。

### 新增「🗺 地图」面板

- 四层叠图：底图 / 省色块 / 州色块 / 省界，各层可单独开关，透明度可调
- 滚轮以光标为中心缩放、拖动平移、「适应」一键铺满
- 悬停显示「省 N · 州 M · land/sea/lake」
- **单击选中省 → 双击直接打开对应的州面板**
- 搜索框：输省号定位到该省质心（1.1 倍），输州号定位到该州全部省份的中心
- 首次点「构建图层」约 **13 秒**，之后走缓存秒开

### 技术验证结论（完整报告见仓库 `work/map_spike_report.md`）

| 指标 | 实测 |
|---|---|
| 地图尺寸 | 5632 × 2048，13264 个省份 |
| 首次构建全部图层 | 13.3 秒（省色/州色/省界/id 图/底图/索引，共 6.4 MB） |
| 全图像素映射 | 1.33 秒，未命中颜色 0 |
| 前端三层叠图 | 加载 19 ms，缩放 61 FPS |
| 单击取省 | 质心点击还原 id 完全正确 |
| **包体影响** | **0（Pillow 本来就在包里，exe 仍 24.2 MB）** |

关键取舍：**不引入 numpy**——纯 Python 遍历 1150 万像素只要 1.33 秒，numpy 只快不到 1 秒却要多 15 MB。

### 还差什么

- 政治视图（按国家着色）与战略区图层：需要层 2 的数据准备
- 涂色改省界（写 provinces.bmp）：高风险，单独设计备份与回滚
