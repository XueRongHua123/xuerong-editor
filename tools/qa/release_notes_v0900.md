## 雪绒的钢铁雄心编辑器 v0.90.0

通用性审计：确认编辑器不依赖任何特定 mod，并把"多 mod 冒烟"变成例行检查。

### 审计结果

全代码扫描 mod 特化痕迹：

| 检查项 | 结果 |
|---|---|
| 硬编码 mod 名 / 路径（MUVLUV、2438003901…） | 0 处 |
| 硬编码国家 tag（ITA、GER、H03…） | 0 处 |
| 硬编码特定文件名（Italy.txt…） | 0 处 |
| 硬编码地图尺寸（5632×2048…） | 0 处 |
| 前端标题写死 mod 名 | **1 处，已改** |

后端本来就没有 mod 分支——取色是 `mod → 原版 → 派生`，开局日期读 `common/bookmarks`，
战略区/铁路先 mod 后原版。唯一特化是页面标题里的 `muvluvCN`，已改为通用标题。

### 新增：多 mod 冒烟脚本

```
python work/qa/regress_all.py
```

对每个 mod 跑：国家数、州数、地图元信息、缓存状态、开局日期，图层已建时再跑一次完整性检查。
无 `map/` 且无 `common/countries` 的纯资源包标记为「不适用」，不算失败。

**实测 4 个真实 mod 全部通过：**

| mod | 国家 | 州 | 地图 | 开局日期 |
|---|---|---|---|---|
| 原版 Hearts of Iron IV | 439 | 1081 | ok | 1936.1.1 |
| muvluvCN_1.19 | 117 | 818 | ok | **1999.8.7** |
| 2438003901 | 512 | 2525 | ok | **1962.1.1** |
| 1521695605 | 333 | 1125 | ok | 1936.1.1 |

开局日期各自从各自 mod 的 bookmark 读出，证明没有全局状态泄漏。

### 通用性规则（写进工作区约定）

1. 禁止硬编码 mod 名、tag、文件名、地图尺寸、州/省数量
2. 路径一律「先 mod 后原版」，mod 缺文件用原版，不报错退出
3. 同一语义的多种写法都要认（`rgb {}` / `hsv {}`、railways 块式与行式、日期块覆盖直接子级）
4. 针对特定 mod 的优化只能做成配置/规则表，不写进代码分支
5. 每版最少在两个真实 mod 上跑 `regress_all.py`
