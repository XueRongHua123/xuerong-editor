# 雪绒的钢铁雄心编辑器 v1.25.0

## 本次改了什么

> **重要更新**｜上线整套 Submod 工作台：新建、排查覆盖、进游戏查错与打包发布一气呵成

这版把「基于原版或别人做好的大型模组再叠一层 Submod」的整条工作流做通了：从建工程、看层叠覆盖、进游戏自动查新增报错到打包发工坊，都能在编辑器里直接完成。同时把诊断耗时从一两分钟压到不到 1 秒，并补上了独立的本地化浏览和编辑界面。

## 一、Submod 工作台（新建 → 排查 → 进游戏 → 打包）

- **新建向导更顺手**：会自动识别已安装的模组供下拉选择，写入正确的模组名称和游戏版本，并自带一张占位封面图；把二级 Submod 放在自定义文件夹后重启，也能顺藤摸瓜找回完整的父模组依赖链。
- **叠加链可视化**：直观展示从原版、父模组到当前 Submod 的加载顺序，查得出每个文件最终以哪一层为准，还能列出 `replace_path` 屏蔽了哪些底层文件。
- **对象级覆盖对比**：按国策、事件、国家精神逐项列出跨层冲突和文本差异，分清哪些是「整份文件覆盖」、哪些是「不同文件里同 ID 撞车导致报错」。
- **一键进游戏检查**：自动启动游戏到主菜单并对比报错日志，只显示你这层模组新产生的报错，还能定位到具体文件和行号；测试结束后自动恢复游戏启动配置 `dlc_load.json`，就算中途意外退出，下次打开编辑器也会自动帮你还原。本地模组目录带中文或与已订阅的工坊模组重名时，也能正常挂载验证。
- **一键打包发布**：导出一份可直接上传工坊的干净目录和 `.zip` 包——自动清理 `.bak` 备份与缓存杂项、自动修正 `.yml` 与 `.txt` 的文件编码（BOM）、补齐 `descriptor.mod` 依赖和封面图，还可顺手写入官方启动器 `.mod` 文件。

## 二、编辑与排查体验提升

- **诊断更快、不再误报父层老毛病**：点「诊断」默认只检查当前 Submod 自己的改动与 `replace_path`，不再耗一两分钟去扫原版地图或把父模组的历史问题算到你头上；需要全链排查时，勾选面板里的「含父层与完整地图」即可。
- **本地化独立浏览与修改**：点击顶部「本地化」后，除了查看缺漏键，现在可以直接搜索关键词、筛选「全部已加载 / 仅当前 mod」、切换简中/英文/日文并当场修改保存。
- **只动自己的模组**：从界面新建国策树、共享焦点、事件、国家精神、科技、装备，以及跨层保存事件或国家精神时，统一写入你当前最顶层的可写模组，不会改坏本地父模组。
- **接管更可控**：诊断面板新增「单文件接管」和「已忽略」列表查看/恢复；批量接管多个目录时带真实进度条，不再重复重载卡死。
- **建筑上限提前拦截**：保存州或省份建筑时，按当前模组链的真实建筑上限提前校验（比如基建默认上限 5 级），防止写进游戏报错。

## 三、修复的问题与启动优化

- **启动与构建更顺畅**：去掉启动时的重复加载；先开端口再在后台载入数据，打开网页即可看到实时加载进度；「构建地图图层」补充了 14 个阶段进度条，不再傻等死页面。
- **脚本写回修复**：修掉了老国策树省略 `x` 或 `y` 坐标导致打开报错、跨层保存事件时残留重复前缀、部分脚本和删决议误写 UTF-8 BOM、外交附庸脚本括号嵌套错位、新建装备漏注册装备类型、新建科技多套一层文件夹块、以及新建人物传参缺默认类型的问题。
- **实验性功能显式标注**：目前「地图编辑」与「造一个新世界」在界面上明确挂上了「实验性」标签与当前局限说明。

## 升级说明

直接下载新版替换旧程序即可，原有的模组文件与配置无需清理。

## 已知限制

- 自建新地图进入游戏在加载省份后的崩溃问题尚未解决，当前仍建议用于基于原版或已有模组制作内容向 Submod。
- 地图编辑与造新世界功能仍标注为「实验性」，未在游戏内完整实测流程前请勿直接用于正式工程。
