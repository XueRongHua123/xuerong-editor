## 雪绒的钢铁雄心编辑器 v1.7.1

放大地图不再糊。

### 原因

v1.0.6 我为了"顺滑"，给 `k > 1.4` 加了 `image-rendering: auto`（双线性插值）。
结果放大到 8 倍时，边界被插值糊成一团涂抹状——**比锯齿更难看清地块边界**。

参考项目在高倍下清晰，用的就是硬边像素（pixelated），不是插值。

### 实测（同一位置 800% 缩放）

| 渲染 | 观感 |
|---|---|
| `auto`（插值） | 边界糊成模糊光带，看不出像素级边界 |
| `pixelated` | 边界硬边锯齿，每个像素都能看清 |

### 改法

```
k < 0.35  →  auto        （缩得很小时抗摩尔纹）
k ≥ 0.35  →  pixelated   （其余全部硬边像素）
```

阈值从 1.4 降到 0.35：只在缩到极小、像素挤在一起时才插值。

### 说明

HOI4 的地图源图就是 5632×2048，放大必然看到像素格。要做"拉多远都锐利"，
只能把省界提成矢量描边（每省轮廓数据几十 MB），这版没做。
