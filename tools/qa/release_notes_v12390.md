## 雪绒的钢铁雄心编辑器 v1.23.9

高程笔刷。地图生成那条线的最后一块（第 16 项）。

### 之前只有地形笔刷

`terrain.bmp` 能刷（改的是「这块地是平原还是山地」），但 `heightmap.bmp` 完全没碰过——
编辑器只读它算山体阴影，不能改。

### heightmap.bmp 是什么

8 位灰度，0 = 海平面，值越大越高。游戏用它算：
- 山体阴影
- 单位移动阻力
- 河流流向
- 海岸线渲染

### 新增接口

```
POST /api/height_paint   {points, height, brush, feather}
POST /api/height_sample  {points, radius}
```

`height_paint`：
- `points` 是地图像素坐标数组
- `height` 是 0-255
- `brush` 是半径（1-60）
- `feather` 开羽化：笔刷内按到圆心的距离做线性插值，中心完全覆盖、边缘几乎不动

`height_sample`：读某几个点附近的高程平均值，用来显示当前高度。

### 实现要点

沿用 `terrain_paint` 的做法：**原地 seek 写单字节**。
`Image.save` 会以 `w+b` 重开文件，在某些路径上直接报 EINVAL，所以不能整图重写。

写之前校验 `heightmap.bmp` 与 `provinces.bmp` 同源——不同源说明有人用 `replace_path`
只换了一张，刷下去会错位。

### 实测

```
刷前采样（800,400，半径1）: 89
刷 317 个像素，高度 200，羽化
刷后采样: 188
```

没到 200 是因为采样半径 1 平均了羽化边缘，中心点是满值。

### 界面

「地形笔刷」上面加「高程笔刷」：

```
在地图上拖拽刷高度（0=海，255=最高）
高度 [====|====] 140
半径 [==|======] 8
[✓] 羽化  [开始刷]
```

「开始刷」是按下去切换的，开了以后在地图画布上左键拖拽就连续刷，
每次 mouseup 后自动清图层缓存并重载高度图。
