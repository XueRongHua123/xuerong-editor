## 雪绒的钢铁雄心编辑器 v1.0.7

交互第二批：**修点穿 bug + 快捷键 + 悬停信息 + 状态栏**。

### 1. 修掉「点 UI 却选中后面的地块」

原因：地图的 `pointerdown` 排除了图层面板，但 **`pointerup` 没有**。
按下时被拦住了，抬起时照样按鼠标坐标取省——而图层面板是绝对定位在画布上的浮层，
面板底下的像素就被选中了。

现在统一成一个判断 `mapEventOverUI(e)`，`pointerdown` / `pointermove` / `pointerup` 三处都用它：

```
#mapTools, #mapSide, #mapRail, #mapHead, #mapStatus, #mapCheckModal, #updModal
```

实测用真实鼠标事件在 9 个 UI 位置点击，修复前图层面板 3 处会误选，修复后 9 处全部不触发。

顺带：鼠标在图层面板上移动时，底部状态栏也不再显示面板背后的省。

### 2. 快捷键

| 键 | 作用 |
|---|---|
| `V` / `P` / `S` / `I` | 浏览 / 涂色 / 改归属 / 吸管 |
| `0` 或 `F` | 适应窗口 |
| `1` | 1:1 原始像素 |
| `+` / `-` | 放大 / 缩小（以地图中心为焦点） |
| `Alt + 滚轮` | 调笔刷半径（1–30） |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做地图编辑 |
| `Esc` | 关检查面板 / 清空选择 |

输入框聚焦时快捷键自动失效，不会干扰打字。
