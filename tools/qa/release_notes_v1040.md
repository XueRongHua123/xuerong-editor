## 雪绒的钢铁雄心编辑器 v1.0.4

**地图检查一键修复**：能安全自动处理的项，点一下就修。

### 现在能修什么

**幽灵省**——`definition.csv` 里定义了、但地图上没有任何像素的省。

这类省常见于：删过省份没清 csv、合并后残留、从别的 mod 抄了 csv 但没抄地图。
游戏加载时它们占着 ID 却不出现，还会让「省号」和「实际地块」对不上。

修复动作：从 `definition.csv` 里删掉这些行（省 0 保留），改前自动备份，改完提示重建图层。

### 界面

地图检查面板多了一个「一键修复」按钮：

```
一键修复   只修能安全自动处理的项    [检查] [省份排行] [一键修复]
────────────────────────────────────────────────────
可修   幽灵省 · 2 个                        [执行]
       删除 definition.csv 里这些行：90001, 90002
```

### 实测

用带两个假幽灵省的测试 mod：

```
修复前：definition.csv 13268 行
预览：  幽灵省 2 个 → 90001, 90002
执行：  已删除 2 个幽灵省
修复后：definition.csv 13266 行
```

0 报错，行数对得上。

### 为什么先只做幽灵省

其他问题不是不能修，是修了容易帮倒忙：

| 检查项 | 为什么不自动修 |
|---|---|
| 州/战略区不连续 | 岛屿、跨海飞地本来就不连续，自动"修"会破坏真实地理 |
| 省份多块连通 | 同上，岛屿省是正常的 |
| 十字交叉像素 | 可以修，但需要判断往哪个方向解（下一版做） |
| 同色省 | 改颜色会改变地图外观，必须人工确认 |
| 铁路断连 | 得知道原本该连哪里，无法推断 |
