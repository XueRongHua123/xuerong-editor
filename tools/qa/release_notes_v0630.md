## 雪绒的钢铁雄心编辑器 v0.63.0

修三处交互问题，都是截图里遇到的。

### 1. 环形菜单与球不同心（缩放后偏移）

原因：界面"大 / 小"档位用的是 CSS `zoom`，而 `getBoundingClientRect()` 返回的是缩放后的视觉像素，
直接拿来设 `left/top` 会被再乘一次 zoom，于是菜单整体偏移。

现在所有悬浮坐标都按 `uiZoom()` 归一化（环形菜单、AI 面板拖动、视口边界判断），
在 1.06 倍缩放下实测七个按钮到球心的距离一致。球体旋转也改成只转图片，不再改变自身包围盒。

### 2. AI 面板"钉死"且超大 / 找不到关闭

- 面板位置改由 JS 计算并夹在视口内：默认右下（按 zoom 换算），`max-height` 取 `视口 - 40`，
  内部滚动；实测 492×652，四边都在视口内，**关闭按钮可见**
- 拖标题栏可移动（`pointermove` 改挂到 window，缩放时按 zoom 折算位移），位置记在本机；双击标题栏回默认位
- **Esc 也能关**；右上角「关闭」按钮保持原位

### 3. 隐藏雪绒 ↔ 显示雪绒互切

环形菜单里的雪绒项现在按当前状态显示：

- 雪绒可见 → 图标 👀、名字「隐藏雪绒」，点一下隐藏
- 雪绒已隐藏 → 图标 🐟、名字「显示雪绒」，点一下叫回来

状态写入 `mascotFloatState`，重启后记住。原来的「隐藏雪绒」固定项已删除，避免和「换衣服」抢位置。
