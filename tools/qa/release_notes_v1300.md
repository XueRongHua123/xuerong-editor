## 雪绒的钢铁雄心编辑器 v1.3.0

**省份细化**：把一个太大的省切成若干块。

### 怎么用

右侧新增「细化」页：

```
细化当前省
把选中的省切成若干块，形状随机而自然，面积尽量均分。
第一块沿用原省号，其余分配新号并写进 definition.csv。

块数 [4]  建议 2–8
[预览]  [应用到地图]
省 13063 切成 4 块，面积 5121 / 4934 / 2159 / 1928（共 14148 像素）
```

先在图上点一个省 → 填块数 → 预览（只算不写）→ 应用（写 `provinces.bmp` + `definition.csv`）。

### 算法

两段：

**1. 最远点采样选种子** — 第一个种子取离区域重心最近的像素，之后每次取离已选种子最远的像素。种子会自动分散到区域的各个角落。

**2. 同步水位生长** — 每轮让所有块各向外长一层，达到面积预算（总像素 / 块数）就停。

试过另外两种，都不行：

| 方法 | 问题 |
|---|---|
| 普通多源 BFS（先到先得） | 某个种子周围细长，长得慢，面积 10760 : 3382 |
| 多源最短路（Dijkstra） | 细长区域全归一个种子，更极端 |
| **同步水位生长** | 每块每轮只长一层，面积天然接近 |

### 实测（muvluvCN 最大的省 #13063，14148 像素）

```
14418 像素 → 4 块：5121 / 4934 / 2159 / 1928
耗时：预览 1.8 秒（含首次载入省号数组），应用 2 秒
```

四个数加起来正好 14148，一个像素不丢。

可以连续细化：切过的省再切一次，编号接着往后排（13265→13268→…）。

### 面积为什么不能完全均分

切出来的块必须**连通**，而省本身的形状不规则——葫芦形、细长形、带海湾的，几何上就切不出四等分。

测试数据里 K=4 时最大块 5121、最小 1928，差 2.6 倍。游戏里省大小本来也不均（muvluvCN 中位数 160 px，最大 14148 px，差 88 倍），所以这个偏差是合理的。

### 安全性

- 应用前必须预览（参数一变，「应用」按钮就锁住）
- 写 `definition.csv` 前 snapshot 备份
- 地图来自原版时直接拒绝写入
- 输出模式下写到 `output/`，源文件不动

### 待补

- **预览时不显示切分形状**（只有面积数字）。下一步可以把预览画到地图上（用现有的选中描边 canvas，给每一块不同颜色），确认形状满意再写盘。
- 新省的州归属沿用原省，需要再手工改（或后续做「批量移入州」）。
