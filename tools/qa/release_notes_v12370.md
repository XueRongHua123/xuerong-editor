## 雪绒的钢铁雄心编辑器 v1.23.7

左侧导航加「开局数据与编辑」直达入口。

### 找不到功能的原因

「编辑」面板藏在**地图视图内部**：左侧导航的「地图」→ 打开地图 → 右侧才出现
「图层 / 编辑 / 细化 / 铁路 / 装备」这一排 tab → 再点「编辑」。

三步。而且第二步「右侧那排 tab」不看地图视图根本看不到。

新加的开局数据面板（舰队、空军、政治、国策、剧本、人物、决议、生成地图）
全在这一排 tab 的「编辑」里，从国策树视图看过去完全没有入口。

### 改法

左侧导航在「🗺 地图」下面加一行：

```
🗺 地图
  ✎ 开局数据与编辑
```

点它直接等于「打开地图 → 切到编辑 tab」：

```js
openMap();
mapBindEvents();
setTimeout(()=>{
  const b = document.querySelector('.side-tab[data-tab="edit"]');
  if(b) b.click();
}, 120);
```

用了 120ms 延迟，等地图视图挂载完再找 tab 按钮。
