## 雪绒的钢铁雄心编辑器 v1.0.0

**新建州**：把选中的省组织成一个新州，写完整的 state 文件 + 本地化。

### 怎么用

涂色面板下方「新建州」：

1. 填省号，空格分隔（如 `221 222 223`）
2. 填州名（中文，会写进本地化）
3. 选类别（rural / town / city / megalopolis / wasteland）
4. 填人力（默认 100000）
5. 点「创建州」

### 生成的文件

**州文件** `history/states/1082 - 接口测试州.txt`：

```
state = {
	id = 1082
	name = "STATE_1082"
	manpower = 150000
	state_category = city
	provinces = {
		221
		222
		223
	}
	local_supplies = 0.0
}
```

**本地化** `localisation/simp_chinese/zz_xuerong_state_names_l_simp_chinese.yml`（带 UTF-8 BOM）：

```
l_simp_chinese:
 STATE_1082:0 "接口测试州"
```

### 几个必须做对的细节

1. **州名是本地化键，不是直接写中文**——HOI4 里 `name = "STATE_1082"`，中文放 loc 文件。直接写中文游戏里会显示不出来。
2. **loc 文件必须带 BOM**，否则游戏读不到（这条正是 v0.96 检查在管的事）。
3. **一个省只能属于一个州**——新建时会把这些省从原州移出。实测：省 221/222 从州 125 移出后，州 125 剩 `[223]`，新州是 `[221, 222, 223]`。
4. **州 ID 自动找空闲**（从 1 开始找第一个没被占用的）。

### 实测

| 检查项 | 结果 |
|---|---|
| 州文件格式 | HOI4 标准结构，能重新解析 |
| loc BOM | `efbbbf` ✓ |
| 重新载入 | 州 1082 → `STATE_1082` / `[221,222,223]` / `city` ✓ |
| 从原州移出 | 州 125 剩 `[223]` ✓ |
| 接口 `/api/state_create` | 正常返回 |

### 和上一版的配合

- 合并：把省并掉（省变少）
- 新建州：把省组织起来（州变多）

两者都是「省 → 州」的归属调整，写入都落在链顶 mod，原版与父 mod 只读。
