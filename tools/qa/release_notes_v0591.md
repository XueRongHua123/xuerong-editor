## 雪绒的钢铁雄心编辑器 v0.59.1

修正科技树位置写回对 `@宏` 的处理。

### 变化

- 拖动科技时，如果它原本写的是 `position = { x = 0 y = @1936 }`，而你把它拖回**同一个值**（1936 那一行），
  文件里仍然是 `y = @1936`，不会被拍平成 `y = 2`。
- 拖到别的行才写数字（例如 `y = 5`）。
- 反过来不会乱套：原本是数字的 x，即使新值恰好等于某个宏的值（比如 2），也不会被写成 `@1936` —— 宏只保留在原位，不跨轴、不跨科技借用。

### 为什么不会飘（再说一次）

游戏读的科技树位置就是 `folder = { name = ... position = { x y } }` 里的这两个数。
编辑器只改它们，`name`、`path`、注释、宏定义一律不动，所以游戏里的位置与编辑器一致。
