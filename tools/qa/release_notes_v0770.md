## 雪绒的钢铁雄心编辑器 v0.77.0

修一个从 v0.57 就存在的**州归属解析错误**：苏联为什么会显示成红色。

### 现象

你的截图里苏联整片红色，但游戏里那块是 BETA 巢穴（H 系国家，颜色 `0 0 0`）。

### 根因

MUVLUV 的开局日期是 **1999.8.7**（`common/bookmarks/the_gathering_storm.txt`），而州的 history 长这样：

```
history = {
	1999.8.7 = {
		owner = H03      # ← 开局生效的就是这个
		remove_core_of = H03
	}
	owner = SOV          # ← 无日期的"最初默认值"，会被上面的日期块覆盖
}
```

HOI4 的语义是：**无日期的直接子级是最初默认值，日期块按时间顺序覆盖**。开局时 1999.8.7 的块最后执行，所以实际归属是 H03（BETA 巢穴）。

我们之前（v0.57 起）一直取"直接子级优先" → 读成 SOV → 政治视图给了俄罗斯的红色。

### 修复

- 新增 `_start_date_for(root)`：读该 mod 的 `common/bookmarks/*.txt`，取最早的 `date =`（本 mod 是 1999.8.7）
- 新增 `_state_owner_effective()`：先扫日期块，取 **≤ 开局日期中最晚的那个** 的 owner；没有再回退到 history 直接子级
- 每个 mod 各用自己的开局日期（不信全局），结果缓存

### 影响范围

| 位置 | 之前 | 现在 |
|---|---|---|
| 州面板的 owner | SOV | H03 / H11（BETA 巢穴） |
| 政治视图颜色 | 苏联红 | 巢穴黑（`color = { 0 0 0 }`） |
| 国家中心的"拥有州数" | 错按 SOV 统计 | 按实际归属统计 |
| 项目体检的州相关项 | 同理受影响 | 同理修正 |

### 验证

- 州 137 克里米亚 `SOV → H03`、州 192 敖德萨 `SOV → H11`、州 193 切尔尼戈夫 `SOV → H11`
- 重建地图缓存 17.9 秒，政治视图里苏联区域变为黑色巢穴
- 视觉巡检 27 状态全绿
