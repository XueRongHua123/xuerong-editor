## 雪绒的钢铁雄心编辑器 v0.77.0

修正州归属解析：history 里带日期块的 `owner` 现在按开局日期生效。

### 问题

MUVLUV 类 mod 的开局日期是 1999.8.7（`common/bookmarks/`），而部分州的 history 是这样写的：

```
history = {
	1999.8.7 = {
		owner = H03
		remove_core_of = H03
	}
	owner = SOV
}
```

HOI4 的语义是：无日期的直接子级相当于最初默认值，日期块按时间顺序覆盖。开局时 1999.8.7 的块最后执行，实际归属是 H03。

旧实现固定取「直接子级优先」，把这类州读成 SOV，导致政治视图、州面板、国家中心的州统计都跟着错。

### 修复

- 新增 `_start_date_for(root)`：读取该 mod 的 `common/bookmarks/*.txt`，取最早的 `date =`，按 mod 缓存
- 新增 `_state_owner_effective()`：先扫日期块，取 **≤ 开局日期中最晚的那个** 的 owner；没有再回退到 history 直接子级
- 每个 mod 使用自己的开局日期，不依赖全局状态

### 影响范围

| 位置 | 修正前 | 修正后 |
|---|---|---|
| 州面板 owner | 按直接子级取（SOV） | 按开局日期取（H03 / H11） |
| 政治视图配色 | 与该州实际归属不符 | 与实际归属一致 |
| 国家中心「拥有州数」 | 统计偏差 | 正确 |
| 项目体检的州相关项 | 同上 | 同上 |

### 验证

- 州 137 克里米亚、州 192 敖德萨、州 193 切尔尼戈夫 的 owner 由 SOV 变为 H03 / H11
- 重建地图缓存约 18 秒，政治视图中对应区域颜色与游戏内一致
- 视觉巡检 27 个界面状态全绿
