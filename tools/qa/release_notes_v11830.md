## 雪绒的钢铁雄心编辑器 v1.18.3

政治图大面积灰色的真正原因找到了——不是无主地块，是国家颜色查不到。

### 根因

muvluvCN 是 1999 世界线，用超国家实体代替了传统国家：

```
EUR（欧洲联盟）  GEU（西欧？）  CEA（中亚？）  AFR（非洲联合）
```

但 `history/states/*.txt` 里的 owner 还是旧 tag：

```
FRA  GER  ITA  BEL  GRE  HUN  BUL  DEN  ENG  FIN  EST  IRQ  AFG  MON  HOL
```

这些 tag 在 CN 的 `COUNTRIES`（只有 116 个）里**一个都没有**。

代码里：

```python
pcb = tag_color.get(ow) or neutral
```

查不到颜色就落到中性灰，于是欧洲、中东、印度整片变灰，看起来像数据缺失。

### 修法

给缺失颜色的 tag 生成稳定回退色：

```python
_tag_fallback_color(tag)   # md5 哈希 → 20 色调色板取模
```

先用 HSV 现算，发现某些色相区间会退化成相近 RGB（红区全是 R=191），
改黄金角分散也只改善一点，最后用预定义调色板（20 种区分度足够的颜色）。

实测 20 个旧 tag 落在 13 种颜色上，撞色可接受。

### 效果

修复前：欧洲、中东、印度、东南亚全是灰。

修复后：这些区域都有颜色了，能看出政治区划。

采样：欧洲内陆 `[200,130,130]`（FRA 的 fallback 色），不再是 `[46,50,46]`。

### 还剩的黑块

图上仍有几块深色，那是**不属于任何州的省**。

CN 的 818 个州覆盖了 10048 / 13264 个省（75.8%），剩下 3216 个不在任何州里。

这和颜色是两回事——这些省在 `history/states` 里确实没被划进任何州，
游戏里应该也是不可进入或 BETA 控制区。

### 一句话

之前判断「灰色是无主陆地」是错的。真正原因是**国家表换了名字、州还引用旧名字**。
这是 mod 数据不一致，但编辑器应该容错，不能因为查不到颜色就整片画灰。
