### 地图检查（左侧工具栏 🔍）

对当前地图跑一遍完整性检查，约 **10 秒**：

| 级别 | 检查项 | 本次结果（muvluvCN 1.19） |
|---|---|---|
| 错误 | 无效省 ID、一省多州 | 0 |
| 警告 | 省份多块不连通、州/战略区不连续、十字交叉、铁路断连 | 4 类（494 / 62 / 37 / 173 处） |
| 提示 | 无主省份、超大省份 | 2 类（3149 块 / 30 个） |

- 每条结果带「定位」按钮，点了直接跳到地图对应位置并选中该省
- 顶部统计胶囊：错误 0 / 警告 4 / 提示 2

**为什么连通性问题算警告**：这类地图里岛屿省、跨海州是常态，标成错误会误导。降级并注明"多为岛屿/飞地"。
