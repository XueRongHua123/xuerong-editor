## 雪绒的钢铁雄心编辑器 v0.81.0

地图界面重构，为后续的涂色编辑功能准备好结构。

### 新的布局

```
┌──────────────────────────────────────────────────────────────┐
│ 地图  5632×2048 · 13264 块   [来源] [搜索] 适应 构建 关闭      │
├────┬──────────────────────────────────────┬──────────────────┤
│ 🖐 │                                      │ 选中省份          │
│ 🏷 │              地图画布                 │ 省 221 / land    │
│ 🖌 │                                      │ 州 125           │
│ 💧 │                                      │ 战略区 1          │
├────┴──────────────────────────────────────┴──────────────────┤
│ 浏览 | 省 221 · 州 125 · 地区 1 |      滚轮缩放 · 拖动平移      │
└──────────────────────────────────────────────────────────────┘
```

- **左侧工具栏**：🖐 浏览、🏷 改州归属、🖌 涂色（占位）、💧 吸管（占位），当前模式高亮
- **右侧属性面板**：选中省份后显示 省/州/战略区/像素数，下方是「移入目标州 / 移出当前州 / 在州面板打开」
- **底部状态栏**：当前模式、光标图像坐标、选中省份摘要、操作提示
- **图层面板**：移到画布右下，可折叠（点标题栏的 −/+），不再遮挡地图主体

### 为涂色功能铺的路

- 模式切换框架已就位：`mapSetMode(mode)` + `.map-tool[data-mode]`，加新工具只需加按钮与分支
- 未实现的工具点一下会提示「这个工具还在开发中」，不会误触
- 属性面板已经是「选中对象 + 操作列表」的结构，涂色时可直接换成「目标省 + 画笔大小 + 撤销」

### 交互细节

- 浏览模式未选省时右侧面板收起，不占空间
- 属性面板的「在州面板打开」会关闭地图并跳到对应州
- 改归属成功后，右侧面板与状态栏同时更新
