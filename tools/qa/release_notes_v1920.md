## 雪绒的钢铁雄心编辑器 v1.9.2

图层面板加了**预设**，一键切换常用视图组合。

### 为什么需要

图层总共 7 个开关 + 7 个独立透明度。要看「州」的分区，得先关掉底图、关掉地形、关掉省色块——
这些组合不会写在界面上，只能自己试。

试不出来就会觉得「州图层没用」。

### 六个预设

```
预设   [地形] [州] [省色块]
       [政治] [战略区] [原始]
```

| 预设 | 打开 | 关掉 |
|---|---|---|
| 地形 | 地形 | 省色块、政治、州、战略区、大洲、底图 |
| 州 | 州 | 省色块、政治、地形、战略区、大洲、底图 |
| 省色块 | 省色块 | 政治、地形、州、战略区、大洲、底图 |
| 政治 | 政治 | 省色块、地形、州、战略区、大洲、底图 |
| 战略区 | 战略区 | 省色块、政治、地形、州、大洲、底图 |
| 原始 | 底图 | 其余全部 |

省界是 canvas 矢量描边（1px 恒定线宽），不占图层，所以预设在切换时不需要管它。

### 记住上次选择

选过的预设存在 `localStorage`，下次打开地图直接恢复。

首次打开按省数决定：超过 8000 个省默认「地形」（省色块在这个量级下是噪点），否则默认「省色块」。

### 手动改图层会取消预设高亮

点了某个预设后再单独勾/取消某层，预设按钮的高亮会消失——表示现在是自定义组合。

### 实测

六个预设逐个切换，每次只有目标图层是开的：

```
地形   → [terrain]
州     → [state]
省色块 → [prov]
政治   → [polit]
战略区 → [region]
原始   → [base]
```
