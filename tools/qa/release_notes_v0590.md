## 雪绒的钢铁雄心编辑器 v0.59.0

这一版把"国策 → 国家 → 州 → 省份 → 科技"这条链补齐了，全部是本地读写，不联任何在线服务。

### 新增

- **科技树位置编辑**：打开科技树 →「✏️ 拖动改位置」，拖完点「💾 保存位置」。
  写回的是 `folder = { name = ... position = { x y } }` 里的 x/y —— **和游戏读的是同一处**，
  只改这两个数字，name、path、注释、宏定义（`@1936 = 2`）都不动，所以进游戏位置与编辑器一致，不会飘。
  单行 `position = { x = 0 y = @1936 }` 和多行写法都支持；没有 position 时自动在 name 后插入。
- **初始外交**：历史编辑器加 `add_opinion`，每行一个 `TAG 数值`。
- **体检扩展**：现在会扫国策里的 `add_ideas` / `has_idea` / `country_event` 引用，报出不存在的精神与事件。
- 省份列表上限 80 → 300。
