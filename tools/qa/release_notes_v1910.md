## 雪绒的钢铁雄心编辑器 v1.9.1

细化不再留下孤儿地块：新省自动加入原州，细化前会提示风险。

### 1. 新省自动加进原州

之前细化完，新省不属于任何州——游戏里没有 owner、没有建筑槽、没有人口。

现在写完 `provinces.bmp` 之后，会改 `history/states/<州>.txt` 的 `provinces` 列表：

```
州 809 改前：5264, 13062, 13063, 13204, 13229, 13236
州 809 改后：5264, 13062, 13063, 13204, 13229, 13236, 13267, 13268
```

改前有 snapshot 备份。

### 2. 细化前提示三件事

预览时把这些直接显示在状态栏：

```
省 13063 切成 3 块，面积 5733 / 4871 / 3538（共 14148 像素）· 形状已画到地图上
⚠ 新省会加入州 809（共 6 省）
```

覆盖的情况：

| 情况 | 提示 |
|---|---|
| 该省属于某州 | 新省会加入州 N（共 M 省） |
| 该州只有这一省 | 新省需要单独建州或并入邻州 |
| 该省有胜利点 | 细化后图标会随质心移到原省残留块 |
| 该省是首都 | 首都位置会落在原省残留块 |
| 该省不属于任何州 | 细化出来的新省也不会有归属 |

胜利点和首都只提示、不自动改——迁到哪一块是设计决策，不能替用户决定。

### 3. 省→州映射改为按加载层优先

同一省被多个州声明的情况普遍存在（原版有州、mod 又定义了同区域的新州）。
现在按 `ROOTS` 顺序取优先级最高的那一层，后面的 mod 覆盖前面的。

真冲突（同一层内两个州都声明同一个省）会单独提示：

```
⚠ 省 13063 同时被州 809 / 822 声明（数据冲突），本次按第一个州处理，建议先修正
```

### 顺带说明

「州」图层的色块本来就是每州一色（`state.png` 按州号取色），和「省色块」是两张独立的图。
要看州的分区，勾「州」图层即可。
