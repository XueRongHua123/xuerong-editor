## 雪绒的钢铁雄心编辑器 v1.19.0

两个功能：孤儿 tag 诊断、政治图严格模式。

### 1. 孤儿 tag 诊断

图层面板底部新增「诊断」区，点一下列出「州里引用了、但国家表里不存在」的所有 tag。

muvluvCN 实测结果：

```
33 个孤儿 tag　涉及 247/818 州　2835 省
国家表 116 个，其中 78 个没有任何州
```

每个 tag 显示覆盖的州数、省数、样本州号。比如：

```
FRA   37 州 / 412 省
      州 1,2,3,5,6,8
```

**这个诊断同时说明 mod 的数据问题有多大**：
247 个州（30%）的 owner 指向不存在的国家，游戏里这些省应该是无主的。
另外 78 个 tag 有国家文件但没有任何州引用——动态 tag 或废弃国家。

### 2. 政治图严格模式

图层面板底部加了个开关：

```
政治严格模式  [ ]
```

- **关**（默认）：孤儿 tag 用哈希 fallback 色，能看出政治区划，方便编辑
- **开**：孤儿 tag 不着色，落到无主灰，**还原游戏里的真实政治图**

实现上是构建时生成两张图：

```
political.png          fallback 色版（0.30 MB）
political_strict.png   严格版（0.27 MB）
```

切换开关只是换 `src`，不重建。

实测欧洲内陆采样：

| 模式 | 颜色 |
|---|---|
| 正常 | `[200,130,130]` FRA 的 fallback 粉 |
| 严格 | `[46,50,46]` 无主灰 |

### 为什么要两个都要

- 编辑时需要看见区划，否则整片灰没法定位
- 校对时需要知道游戏里实际长什么样，否则会误以为编辑器画错了

同一个 mod 数据，两种视图，各回答一个问题。
