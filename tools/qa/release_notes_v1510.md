## 雪绒的钢铁雄心编辑器 v1.5.1

移除编辑器工具栏里那个旧的「🎮 预览」按钮。

### 为什么删

它是早期的国策预览（弹窗 + 内联 SVG），v1.4.0 做了新的图形预览之后，两个功能重叠：

| | 旧预览 | 新预览 |
|---|---|---|
| 节点图标 | 无 | 真实图标 |
| 节点尺寸 | 260×100（很大，看不清全貌） | 88×88（HOI4 国策格比例） |
| 互斥显示 | 无 | 红色虚线 |
| 从预览跳到编辑 | 做不到 | 双击直达 |
| 事件树 | 无 | v1.5.0 有 |

旧的就是个粗糙缩略图，留着只会让人不知道该点哪个。

### 删了什么

- 工具栏按钮 `#focusPreviewBtn`
- 弹窗 DOM `#focusPreview`（`fpv-card` + `#focusPreviewSvg`）
- 两个函数 `openFocusPreview` / `drawFocusPreview`（1939 字符）
- 相关 CSS（`#focusPreview`、`#focusPreview.show`、`#focusPreviewSvg`、6 行 `.fpv-*`）
- 一处 close 事件绑定

页面从 382132 字符降到 379854。

### 验证

```
旧按钮存在：false
新图形预览：true
事件树预览：true
其他「预览」按钮（地图合并的「预览影响」、细化的「预览」）保留
```

回归测试：新的图形预览仍能点节点跳转到编辑器（`已定位到 AFR_UnbreakableDefence`）。
