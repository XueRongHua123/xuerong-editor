## 雪绒的钢铁雄心编辑器 v0.68.0

历史编辑器里的「开局装备变体」从只读变成可增可删。

### 新增

打开「国家中心 → 历史 → 开局装备变体」，顶部有「＋ 新增变体」，填：

- 名称（如 `TestJet`）
- 底盘 type（如 `fighter_equipment_0`）
- 图标 GFX 名（可留空）
- 模块，每行一个 `槽位 = 模块`

写进历史文件的是一个标准块：

```
create_equipment_variant = {
	name = "TestJet"
	type = fighter_equipment_0
	icon = GFX_TestJet
	modules = {
		fixed_main_weapon_slot = fighter_weapon_1
		engine_slot = engine_1
	}
}
```

### 删除

每个变体行右侧有「删除」，二次确认后整块移除。写前自动备份，可用「🕘 备份」回滚。

### 校验

- 名称只能字母数字、空格、下划线、连字符，最长 60
- 重名直接拒绝
- 底盘格式非法拒绝；装备表有数据时还会校验底盘是否存在
- 槽位/模块 id 只允许字母数字下划线
- 插入位置按花括号深度定位到最后一个顶层块之后，不会落进别的块里
