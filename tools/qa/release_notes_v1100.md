## 雪绒的钢铁雄心编辑器 v1.1.0

第三批第一项：**面板结构整理**。把浮在画布上的图层面板收进右侧栏，用 Tab 切换。

### 之前的问题

右侧挤了三样东西：

- 浮在画布右上角的图层浮层（遮挡地图）
- 右侧的属性面板（选中省才出现）
- 检查/排行/修复又是独立的弹窗

功能越加越多，界面却越来越乱。

### 现在

```
┌──────────────────────────────────────────────────┐
│ 地图 3072×4096 · 17324 块    [来源] [搜索] 适应 … │
├────┬──────────────────────────────┬──────────────┤
│ 🖐 │                              │ 图层 │ 编辑  │
│ 🏷 │                              │──────────────│
│ 🖌 │          地图画布             │ 图层控制     │
│ 💧 │                              │ 8 个滑块     │
│ 🔍 │                              │ 来源链       │
├────┴──────────────────────────────┴──────────────┤
│ 浏览 | 17% | 省 221 · ...                         │
└──────────────────────────────────────────────────┘
```

右侧 268px 一个栏，顶部两个 Tab：

- **图层**：8 个图层的开关与独立透明度、来源链、清理缓存
- **编辑**：选中省属性、涂色工具、省份合并、新建州

点地图上的省会自动切到「编辑」页，不用手点。Tab 选择记在 `localStorage`，下次打开还是上次那页。

### 顺带修的问题

改布局时踩了一个坑：原来的代码用 `#mapSide.empty{display:none}` 控制右侧栏显隐，
选中省时移除 `empty`、移出时加上。

面板搬进右侧栏后，侧栏必须常显（图层面板在里面），但 `mapHideOps` 还在加 `empty` 类，
结果整个右侧栏宽度变成 0——截图里地图占满全宽、什么都看不到。

现在把 `empty` 这套逻辑去掉了，侧栏常显，用 Tab 切换内容。
