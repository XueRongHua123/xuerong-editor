## 雪绒的钢铁雄心编辑器 v1.4.1

把国策树预览和编辑器打通：**预览里点一个节点，直接在编辑器里定位到它**。

### 之前的问题

预览是独立弹窗、只读；编辑器本来就有 SVG 图形视图。同一份数据画两遍，看完预览还得自己在编辑器里找。

### 现在

预览里选中节点 →「在编辑器中打开」（或直接双击节点）：

```
预览关闭 → 编辑器切到那棵树 → 该节点选中并滚到视野中央 → 底部提示「已定位到 AFR_UnbreakableDefence」
```

右侧属性面板同步显示它的原始坐标、前置、互斥、可编辑字段。

### 两边的分工

| | 用途 |
|---|---|
| **预览** | 看全貌：节点总数、连线密度、有没有孤岛，下拉切树 |
| **编辑器** | 改内容：拖位置、加前置/互斥、写效果、批量操作 |

预览是「地图」，编辑器是「现场」。以前是两个孤岛，现在预览负责带路。

### 实测

`MUV_AFR` 53 节点，点第 4 个节点 `AFR_UnbreakableDefence`：

```
弹窗关闭 ✓
编辑器切到 MUV_AFR ✓
目标节点存在于画布 ✓
状态栏：已定位到 AFR_UnbreakableDefence ✓
右侧显示 x=10 y=2 前置 AFR_EvaluateDefenceLineCapability 互斥 AFR_PrepareForAllPossibilities ✓
```

### 顺带修的

预览按钮在国策树面板里渲染成了纯文字（`.btn` 的幽灵样式），改成显式背景边框。
