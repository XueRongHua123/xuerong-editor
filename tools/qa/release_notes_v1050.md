## 雪绒的钢铁雄心编辑器 v1.0.5

一键修复新增第二项：**十字交叉像素**。

### 什么是十字交叉

地图上常见这种 2×2 排列：

```
A B
B A
```

对角线同省、正交不同省。游戏里这会形成一条斜角接缝，两个省在这一点上"够不到"对方——
部队走位、补给、边界显示都会出怪事。

### 怎么修

把每个交叉点解成两种合法形状之一：

```
A A        A B
B B   或   A B
```

选哪个看邻域：A 在上方更连贯就纵切，A 在左方更连贯就横切，判断不了就默认横切。

改动只动**一个像素**（把某个 B 改成 A），不会凭空扩张某个省。

### 迭代到收敛

改像素会产生新的交叉，所以修复是多轮的，最多 4 轮，直到数量不再下降。

**实测（muvluvCN 1.19 的 173 处）**：

```
第 1 轮：173 → 27
后续轮：27 → 少量 → ...
结果：  4 轮共修 179 处，剩余 1 处
耗时：  22.8 秒（每轮重扫整幅约 3.5 秒）
```

配套有撤销：改动记录成区块，出问题点「撤销上一笔」即可回滚。

### 界面

一键修复面板现在两行：

```
可修   幽灵省 · 0 个                                       无需处理
可修   十字交叉像素 · 173 处   把 2×2 的 A B / B A 解成…   [执行]
```

顶部统计：`幽灵省 0  十字交叉 173`。

### 一个已知限制

撤销备份用的是**包围盒**：173 个交叉点散布全图，包围盒几乎等于整幅（5490×2034），
所以一次撤销备份约 33 MB。

功能性没问题，但连续修多次会占磁盘。下一版会改成按网格聚簇的小区块。

### 顺带

v1.0.4 的「幽灵省 0 个」这一行现在也会显示（以前是直接不出现），让人知道这一类已经干净。
