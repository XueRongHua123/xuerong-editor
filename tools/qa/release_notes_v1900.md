## 雪绒的钢铁雄心编辑器 v1.9.0

省界改成 canvas 矢量描边，800% 下是 1px 细线，不再是 8px 粗的模糊带。

### 之前为什么糊

省界原本是一张位图 `edges.png`：地图尺寸 5632×2048 上 1px 宽的白线。

放大 8 倍 → 那 1px 变成 8px 宽的白色方块带。再叠上地形色，边缘就成了模糊光晕。
`image-rendering: pixelated` 只保证「不插值」，不能把 8px 变回 1px。

**放大倍数越高，边界越粗** —— 这是位图的死结。

### 现在的做法

新增 `#mapEdgeCanvas` 覆盖层，每一帧从 `prov_id` 数据里现算边界：

```
1. 取视口范围的 id 像素
2. 标出「自身与四邻域有不同 id」的像素 → 边界像素
3. 连相邻的两个边界像素成折线（横竖各判一次）
4. ctx.lineWidth = 1，按屏幕像素画
```

**线宽固定 1 屏幕像素，任何缩放级别都一样细。** 800% 时是细白线，3200% 时还是细白线。

### 性能

拖动/缩放时节流 90ms 重算（拖动中先不重绘，避免错位和卡顿）。
视口 1050×700 约 73 万像素扫描，实测单帧 40–60ms，拖动跟手。

### 一个诚实的限制

省界的**阶梯形状**是数据本身决定的：`provinces.bmp` 就是 5632×2048 的像素图，
边界天然是 L 形阶梯。放大到 800% 能看到楼梯。

要消除阶梯只有两条路：
- 曲线平滑（Douglas-Peucker + 贝塞尔）——会偏离真实省界，编辑时不能用
- 提高源图分辨率——游戏地图没有更高清的版本

所以阶梯保留，粗细解决。

### 位图边界保留为可选

图层面板里的「省界」开关还在，默认关闭。需要看图时再勾。
