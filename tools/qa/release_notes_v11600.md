## 雪绒的钢铁雄心编辑器 v1.16.0

AI 助手能记住上下文了。

### 之前

每次提问只发两条消息：

```json
{"messages": [{"role": "system", ...}, {"role": "user", ...}]}
```

问完「帮我看下这个国策的效果」，再问「那它的前置条件呢」，模型不知道「它」指什么。

界面里有个「最近提问」列表，但那个只用于**点一下把问题填回输入框**，从来不发给模型。

### 现在

发送时把最近几轮问答一起发给模型：

```json
{"messages": [
  {"role": "system", ...},
  {"role": "user", "content": "第一问"},
  {"role": "assistant", "content": "第一答"},
  {"role": "user", "content": "第二问"},
  {"role": "assistant", "content": "第二答"},
  {"role": "user", "content": "当前提问 + 附加上下文"}
]}
```

### 上下文条数可调

「最近提问」上方新增控制条：

```
上下文 [6 轮 ▾]  [清空]
```

选项：0 / 2 / 4 / 6 / 8 / 12 轮。

- **0 轮** = 关闭多轮，回到单次问答（省 token）
- **6 轮** = 默认

后端还会再做一次截断（最多 12 轮），防止前端传超长历史把模型窗口挤爆。

### 实测

三轮历史 `Q1/A1 → Q2/A2 → Q3/A3`：

| 设置 | 发出去的消息数 |
|---|---|
| 12 轮 | 6 条（全部 3 轮） |
| 6 轮 | 6 条（全部 3 轮） |
| 2 轮 | 4 条（最近 2 轮） |
| 0 轮 | 0 条 |

顺序是时间正序（Q1 在前），因为界面列表是新的在前，发送前做了反转。

### 清空

「清空」按钮直接清掉内存里的历史，界面显示「暂无历史，多轮上下文未启用」。
