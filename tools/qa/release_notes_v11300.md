## 雪绒的钢铁雄心编辑器 v1.13.0

战略区能建了：列表、新建、改范围、删除。

### 数据格式

`map/strategicregions/*.txt`：

```
strategic_region={
	id=1
	name="STRATEGICREGION_1"
	provinces={ 221 271 296 ... }
	weather={ period={ ... } ... }     ← 很长
}
```

原版有 304 个。

### 四项功能

| 操作 | 说明 |
|---|---|
| **列出** | id、名字、省数，标注是否来自原版（原版只读） |
| **新建** | id 留空自动取最大值 +1；**weather 块从现有区复制** |
| **改范围** | 用地图上已选的省整块替换 `provinces={}` |
| **删除** | 摘掉整个块；文件里没有其它块就删文件 |

### weather 怎么办

新建战略区最大的坑是 `weather` 块——每个区都有一大段气候定义（多个 period，温度/降水/雪）。

如果留空，游戏里这个区没有天气数据。

做法：从任意一个现有战略区里抠出 `weather=` 块，原样复制到新建的文件里。
实测新建 305 号区，返回 `天气块已复制`。

### 省份冲突检查

一个省只能属于一个战略区。新建时先查：

```
这些省已属于别的战略区：[(17300, 12)]
```

有冲突直接拒绝，不会写出坏数据。

### 实测

```
列表      304 个
新建      305（2 省，天气块已复制）
改范围    305 现在覆盖 3 个省
删除      已删除战略区 305 及其文件
```

后端复查：新建后 count 从 304 变成 305，目录文件数 226 → 227。

