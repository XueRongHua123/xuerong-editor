## 雪绒的钢铁雄心编辑器 v1.2.0

地形层换成**游戏配色 + 高度图山体阴影**，全过程用 Pillow 的 C 操作，0.44 秒完成。

### 效果

![高度阴影地形](work/qa/shots/v112_hillshade_full.png)

日本中部的山地、朝鲜半岛的丘陵、关东平原的过渡都出来了，海洋保持均匀深蓝。

### 做法

```
terrain.bmp（地形索引） + common/terrain/*.txt（索引→类别）
  → 改调色板 → 地形类别色图                     Pillow, 0.03s
heightmap.bmp（高度）
  → 左右/上下差分 → 有符号梯度                  ImageChops.subtract
  → point 线性映射 → add 合成 = 明暗图          Pillow, 0.03s
  → 地形色 × 明暗（composite）                  Pillow, 0.08s
海洋/湖泊单独用弱阴影                           Pillow, 0.09s
```

**总耗时 0.44 秒**。之前用逐像素 Python 循环估算要 30–40 秒，快约 70 倍。

关键是 `Image.point()` 只对 256 个灰度值调用一次查找表函数，不是对 1258 万像素逐个调用。

### 光照

西北方向（-0.62, -0.62, 0.48），东侧高、南侧高的地形变暗——这是地形图通用的表示法，
山坡朝向不同亮暗不同，视觉上就有立体感。

### 保留回退

如果某个 mod 没有 `heightmap.bmp` 或尺寸不匹配，自动退回原来的纯色块渲染，不会报错。
