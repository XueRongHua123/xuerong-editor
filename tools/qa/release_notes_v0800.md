## 雪绒的钢铁雄心编辑器 v0.80.0

地图层 2 第三项：**战略区图层**。

### 新增

图层面板新增「战略区」，按 `map/strategicregions/*.txt` 给地图上色：

- 每个战略区一种柔和色，222 个区一眼分得清
- 勾选时省色块自动压暗到 30%，避免两层打架
- 悬停信息扩展为「省 N · 州 M · **地区 R** · land」
- 搜索框输入**战略区号**可直接定位到该区所有省份的中心（原有省号/州号定位保留）

### 实现

- 新增 `_strategic_regions(root)`：解析 `strategic_region = { id / name / provinces }`，
  先在 mod 找、没有再用原版；返回 `省 → 地区` 映射与地区列表
- 图层 `region.png` 与 `province.png` 同一趟像素循环生成，不额外扫描
- `prov_index.json` 每条增加 `region` 字段；另存 `regions.json`（id / name / 省份数）
