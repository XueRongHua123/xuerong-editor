## 雪绒的钢铁雄心编辑器 v0.76.0

地图层 2 第二项：**在地图上改省归属**。

### 用法

1. 打开「🗺 地图」，单击任意一个省
2. 左上角信息框下面展开三件东西：**目标州号输入框** / 「移入州」/「移出州」
3. 目标州号默认填当前所属州；要换州就改成别的号，点「移入州」
4. 省不属于任何州时，「移出州」自动置灰

改完状态栏会写清楚：`省 111：州 900 → 州 901`，左上角也立刻更新为「省 111 · 州 901」。

### 写入逻辑

- 先在旧州的 `provinces = { ... }` 里删掉这个省，再写进新州
- 列表整体重建，其它内容（`history`、`buildings`、注释、BOM、CRLF）逐字保留
- 写前自动 `snapshot()`，可用「🕘 备份」回滚
- 原版目录里的州只读，会明确拒绝
- 目标州不存在 / 省 id 非法 / 已经在该州（no-op）都有对应的返回

### 一个已知限制

改完归属后，地图上的**州色块不会立刻更新**——那是缓存图层，需要点「构建图层」重建（约 17 秒）。
状态栏会提示这一点，避免误以为没生效。
