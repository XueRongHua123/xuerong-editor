## 雪绒的钢铁雄心编辑器 v1.21.6

科技树预览的四条改进。

### 1. 节点加宽，显示科技名

格子从 34px 宽、22px 高，改成 **76×30**，上面一行显示科技名（超 9 字截断），下一行显示年份。

```
┌──────────────┐
│ infantry_…   │
│    1936      │
└──────────────┘
```

### 2. 接上缩放/拖拽

复用国策树预览的 `makePannable(svg, body)`，鼠标拖动平移、滚轮缩放。

### 3. 点节点高亮前置链

点一个节点，沿 `leads_to_tech` 反向递归找完所有前置，把整条链染成琥珀色（节点描边 2px、连线同色）。

再点一次取消。

```
点 infantry_weapons1 → 「infantry_weapons1 的前置链：1 个」
  高亮 2 个节点、1 条连线
```

### 4. 背景色

原来写 `var(--bg2,#0e1116)`，但 `--bg2` 从没定义过，一直落到黑色兜底值。
改成 `var(--bg)`，跟编辑面板一致（`rgb(243,241,234)`）。
