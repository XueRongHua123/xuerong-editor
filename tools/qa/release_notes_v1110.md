## 雪绒的钢铁雄心编辑器 v1.1.1

第三批第二项：**输出目录模式**。改动写到独立目录，源 mod 一个字节不动。

### 为什么需要

直接改 mod 文件的风险：改坏了要翻备份、撤销栈只覆盖单步、多 mod 叠加时不知道落到了哪个文件。

参考项目的做法是先写 `output/`，满意了再复制回去。这版照这个思路做。

### 怎么用

地图顶栏「播放集」面板底部：

```
输出模式
开启后所有改动写到 work/output/<mod名>/，源 mod 一个字节不动；
满意了再点「应用回源」复制回去（原文件会先备份）。

[输出模式：关闭]  [应用回源]  [清空输出]
已写 0 个文件 · 0 KB · 源 mod 未改动
```

### 覆盖范围

| 写入类型 | 输出模式下的行为 |
|---|---|
| 文本文件（州、国家历史、国策、事件、本地化…） | 写到 `output/<mod名>/<相对路径>` |
| `provinces.bmp` | 首次写时把源 bmp 复制到 output/，之后改副本 |
| 新建文件（新建州等） | 同上 |

**读取优先输出目录**——这样开了输出模式改完立刻能看到效果（地图重建读的是输出副本），
但源文件没被动过。

### 实测

```
1) 开启输出模式 → on=True
2) 源 provinces.bmp md5: ba957573894f
3) 涂色 81 像素 → commit ok
4) 源 bmp md5 仍是 ba957573894f  ← 源文件未变
   输出副本 md5: 3093f88d0f1f     ← 副本被改
5) 读输出副本 (1500,1500) = (255,0,255)  ← 读到了改过的
6) 关闭 → 恢复直接写
7) 清空输出 → 目录删除
```

### 应用回源

点「应用回源」时：

1. 遍历 `output/<mod名>/` 下的每个文件
2. 找到同名的已加载 mod
3. **先 snapshot 备份源文件**，再复制
4. 返回复制的文件列表和跳过项（比如同名 mod 没加载）
