# 雪绒的钢铁雄心编辑器 v1.23.43

## 本次修的问题

### 共享焦点一个都保存不了

`common/` 下那批共享国策（`common_refugee_tech_sharing`、`common_adopt_powered_suits`、`common_experience_of_BETA_war`、`common_refugee_support_request` 等）此前点保存全部失败——界面上只有底部一闪而过的「保存失败」，文件一个字节都没动。

原因在 `save_focus()` 写回文件后的自校验：它重新扫文件确认能找得到刚写的节点，但正则只匹配 `focus = {`，而共享焦点在文件里写的是 `shared_focus = {`。扫不到自己刚写的内容，判定失败，整份改动回滚。

修法：校验正则同时认 `focus` 和 `shared_focus`。

### 「保存全部」丢字段

`saveAll()` 原来只传 `x`、`y`、`prereq`、`mutex` 四个字段，`cost`、`icon`、`effect`、`select_effect` 全部丢弃。所以在属性面板里改成本、改图标、填快捷效果，点「保存全部」之后只有位置和连线变了。

改成遍历全部八个字段，有值就带。

## 本次加的改进

### 面板输入实时进 dirty

属性面板里的八个输入框（X、Y、成本、图标、效果、选中效果、前置、互斥）现在挂上了 `input` 监听，改一个字就立刻记进「未保存」列表——画布上那个节点的边框会从实线变橙色虚线，顶部「未保存」计数同步上涨。

不用再点一下别处才触发。这样「我到底改了没有」这件事是看得见的。

只有第一次变脏时才重画画布，之后的每次按键只更新统计数字，避免每敲一个字就重建整个 SVG。
