## 雪绒的钢铁雄心编辑器 v0.62.0

悬浮球、看板娘、AI 面板、列表弹窗一起改。

### 悬浮球：环形菜单

单击（或右键）球体，七个功能绕球展开，单向环形排布，hover 显示名称，球体同时旋转 45° 并带光晕：

- 💬 AI 助手 / ⌘ 命令面板 / 🩺 项目体检 / 🌍 国家中心 / 🗺 州·地块 / 👗 换衣服 / 👀 隐藏雪绒
- 展开动画 280ms 缓动（scale + 位移 + 透明度），点空白处收起
- 贴屏幕边缘时按钮会自动夹进视口，不会被裁掉
- 双击不再绑命令面板（避免与单击冲突），唯一入口就是这个环

### 看板娘面板

- **自由缩放**：右下角拖拽手柄调宽（200–560px），双击手柄复位；尺寸记在本机
- **快捷换装**：底栏 `‹ 经典 ›` 直接切皮肤，不用开衣橱面板；换完名字实时更新
- 衣橱面板里换皮肤，底栏名字也会跟着变

### AI 面板

- 不再钉死：拖标题栏可移动，位置记在本机；双击标题栏回到右下默认位
- 宽度改为 `min(430px, 视口-28px)`、高度 `max-height: calc(100vh - 60px)`，小窗口也不会超出屏幕

### 列表弹窗

- 国家中心 / 州 / 体检 / 历史 / 卸载 / 快捷键统一收敛到 `min(1040 × 740)` 的居中卡片，圆角 18px，遮罩加轻微模糊
