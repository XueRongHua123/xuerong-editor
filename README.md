# 雪绒的钢铁雄心编辑器

> 专为《钢铁雄心 IV》（HOI4）社区打造的 **Submod 工作台** —— 本地运行、免费开源代码、禁止商业牟利

本地运行的 HOI4 模组与 Submod 工作台。基于 Python 服务 + 浏览器界面，打包后为单文件 exe，无需安装，也不依赖任何在线服务。

如果你希望在《钢铁雄心 IV》原版或大型 mod（例如各类历史、架空、现代改档）之上再叠一层，制作自己的 **Submod**，这个工具可以让你可视化地完成读取、覆写、本地化、校验、进游戏查错与打包发布，而不必手改几十个分散的脚本文件。

> 本软件由开源模型 **DeepSeek v4.1 flash 1017** 参与开发，是面向《钢铁雄心 IV》模组制作社区的共有财富。

## 能做什么（Submod 工作台）

- **完整叠加链与 `replace_path` 解析**：按 `descriptor.mod` 的 `dependencies` 自动串联多级父 mod 与子 mod，可视化查看每一层的加载顺序、同名文件覆写，以及哪些下层目录被 `replace_path` 整目录屏蔽
- **对象级覆盖对比**：跨层追踪国策、事件与国家精神，直观区分「同名文件整文件覆写」「跨树同名覆盖」与「不同文件重复定义（HOI4 报错）」
- **8 大核心域跨层编辑与接管**：
  - **国策树**：可视化画布、拖拽改坐标、连线建前置/互斥、批量操作、跨层接管保存与差异预览
  - **事件**：列表与事件树编辑、选项/触发条件/immediate/配图表单、跨层接管
  - **本地化**：独立浏览与就地编辑、`简体中文 / English / 日本語` 切换、缺失本地化一键扫描与补全（自动为 `.yml` 写入 UTF-8 BOM）
  - **国家精神**：名称与描述（中/日/英）、modifier 表格、图标选择器、`allowed/trigger` 编辑、跨层接管
  - **决议**：决议与分类读取、参数编辑与分类注册检查
  - **人物**：将领/顾问/国家领导人读取与编辑
  - **科技**：编辑表单与科技树视图、按 folder 真实坐标布局、拖线建前置
  - **州（建筑 / 资源 / 属性）**：按州查看并跨层接管修改工业、资源与人口/分类属性
- **保护原版与创意工坊目录**：游戏本体与父 mod 默认只读，所有保存动作只写入当前可写的 Submod 层，不会改坏原版或订阅的工坊文件
- **进游戏检查（主菜单报错差分）**：一键临时切换测试叠加链并启动 `hoi4.exe` 至主菜单，将 `error.log` 与依赖基线做差分，把当前 Submod 新增的报错精准定位到具体文件与行号
- **一键打包与诊断包**：导出工坊就绪目录并可选在官方启动器目录生成 `.mod` 描述文件；遇到异常或疑难报错时，可通过错误卡片或诊断面板点击 `📦 导出诊断包` 生成脱敏的 `xuerong-diag.zip`
- **基础维护域**：书签（开局日期）、装备与装备设计器、国家与外交 / OOB（保留日常使用与缺陷维护）

## 额外工具与实验性功能

- **日常辅助**：`Ctrl+K` 全局命令面板、本地诊断（OOB 未点名 / sprite 拼写 / 决议类别 / `replace_path` 断链一键接管目录）、项目体检、文件级备份与 `Ctrl+Z` / `Ctrl+Y` 撤销重做
- **AI 助手**：雪绒悬浮窗，支持 OpenAI / DeepSeek / Anthropic / Gemini / Ollama / OpenAI 兼容接口（需自行配置本地 API Key）
- **三语界面与双主题**：中文 / English / 日本語，雪夜（暗色）/ 纸页（暖白浅色）/ 跟随系统
- **地图编辑（实验性）**：支持省色块/州/战略区/地形/高程/铁路图层浏览、涂色改省界、地形与高程编辑、省份合并与新建州，已通过多模组读取与静态可读性校验，但尚未完成《钢铁雄心 IV》实机对局验证
- **造一个新世界（实验性）**：程序化生成包含地图、国家、州与部队的独立 mod 骨架；目前产物在游戏实机启动时存在已知崩溃，仅可用于格式与生成器预览，**不可用于正式游玩工程**

## 下载

到 [Releases](../../releases) 下载最新的 `雪绒的钢铁雄心编辑器.exe`，双击运行即可在浏览器中打开工作台。

首次打开时，先在欢迎页确认或选择《钢铁雄心 IV》游戏目录，再选择已有 mod 文件夹（认准里面包含 `descriptor.mod` 的那一层）或新建一个 Submod。

## 从源码运行

```bash
pip install -r requirements.txt
python focus_editor.py --mod "你的mod目录"
```

不带 `--mod` 会先打开界面，再在页面中选择或新建 mod。

游戏目录默认自动探测常见 Steam 路径，也可以用 `--game` 指定：

```bash
python focus_editor.py --game "E:\SteamLibrary\steamapps\common\Hearts of Iron IV"
```

## 打包

Windows：

```powershell
.\build.ps1
```

产物输出在 `dist/`。

## AI 配置与隐私说明

- AI 的 API Key 只保存在本机 `ai_config.json`，不会上传；该文件已被 `.gitignore` 排除，不要提交到仓库；
- 所有 mod 文件读写都在本机完成，不联网上传任何模组内容；
- 游戏安装目录与只读父 mod 层禁止写入，保存请求会被拦截；
- 写盘修改前自动生成 `.bak` 与历史快照，支持撤销恢复；
- 导出的脱敏诊断包（`xuerong-diag.zip`）会自动剔除系统用户名、用户主目录路径及常见 API/密码凭据，且不包含模组脚本正文。
